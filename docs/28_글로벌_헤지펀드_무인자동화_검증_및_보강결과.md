# 글로벌 헤지펀드 / 365일 24x7 무인자동화 검증 및 보강 결과

> 최신 기준(2026-05-31): Atlas Investment은 토스증권 공식 API 출시 전 안전한 PAPER/DRY_RUN 운용 OS입니다. 완성된 글로벌 헤지펀드 또는 실거래 봇으로 판정하지 않습니다. 토스 플랫폼 범위는 KR/US 주식·ETF·채권·미국주식 옵션 중심이며, 직접 선물·현물 FX·직접 원자재 거래는 공식 지원 전까지 제외합니다. 실거래는 공식 API adapter 구현, read-only reconciliation, 30일 heartbeat, promotion evidence 통과 후에만 검토합니다.

작성일: 2026-05-31

## 요청

다음 두 가지를 확실하게 검증했다.

1. Atlas Investment이 글로벌 모든 투자를 수행하는 초거대 헤지펀드가 확실하게 되었는가
2. Atlas Investment이 365일 24/7 완벽한 무인 자동화가 되었는가

검증 결론은 명확하다.

- 1번: **아니다. 아직 글로벌 모든 투자를 수행하는 초거대 헤지펀드는 아니다.**
- 2번: **아니다. 아직 365일 24/7 완벽한 무인 자동화 시스템은 아니다.**

이 결론은 실패가 아니라 안전한 판정이다. 실거래 자동화 프로그램은 부족한 상태를 `ok`로 표시하면 안 된다. Atlas Investment은 이제 이 판정을 코드로 직접 수행한다.

## 이번에 추가한 검증 명령

새 CLI:

```bash
.venv/bin/python -m atlas_investment.cli hedgefund-readiness
.venv/bin/python -m atlas_investment.cli global-readiness-audit
.venv/bin/python -m atlas_investment.cli autonomy-audit
```

세 명령은 같은 엄격한 준비도 감사를 실행한다.

출력 파일:


## 항목별 판정

### 1. 글로벌 투자 유니버스

판정: `blocked`

증거:

- 현재 tradable 자산 수: 16개
- 시장: KR, US
- 초거대 글로벌 헤지펀드 기준에는 부족

필요 보강:

- KRX 전체 종목
- 미국 전체 상장주식/ETF
- 유럽, 일본, 홍콩/중국, 신흥국
- 상장폐지/거래정지/관리종목 이력
- 종목 마스터의 survivorship bias 제거

### 2. 자산군 커버리지

판정: `blocked`

현재 커버:

- stock
- ETF

부족:

- bond
- future
- option
- FX
- commodity

주의:

파생상품과 FX는 증거금, 만기, 롤오버, 강제청산, 레버리지 규칙이 완전히 다르다. 현재 주식/ETF 모델에 억지로 얹으면 위험하다.

### 3. 실주문 브로커

판정: `blocked`

증거:

- 공식 REST API base URL 없음
- 공식 WebSocket URL 없음
- 공식 app key 없음
- 공식 app secret 없음
- 공식 계좌 식별자 없음
- `TossLiveBroker`는 의도적으로 비활성

필요 보강:

- 공식 지원 주문 API 문서 확보
- 실시간 시세/호가/체결 API 확보
- 실계좌 조회 API 확보
- 주문/정정/취소/체결 이벤트 구현
- 소액 수동 승인 주문 테스트

### 4. read-only reconciliation

판정: `blocked`

증거:

- `tossctl` 없음
- 계좌/포지션/주문/체결 스냅샷을 실계좌와 대조하지 못함

필요 보강:

- read-only 계좌 조회 경로 설치
- 10영업일 이상 내부 상태와 브로커 상태 일치 검증
- 불일치 시 신규 주문 차단

### 5. 데이터 품질

판정: `blocked`

증거:

- 데이터 레이크 OHLCV CSV 수: 4개 수준
- sample/yfinance/hybrid는 연구/개발용 fallback
- 기관급 survivorship-bias-free 데이터가 아님

필요 보강:

- 유료/공식 데이터 공급원
- 배당, 분할, 권리락, 거래정지, 상장폐지 반영
- 데이터 신선도 SLA
- 공급원별 checksum과 row count 검증

### 6. 24x7 데몬

판정: `degraded`

이번 보강:

- `scripts/atlas_investment_daemon.sh` 추가
- `config/automation_policy.json` 추가
- lock file, heartbeat file, 반복 healthcheck 구조 추가

아직 부족:

- systemd/supervisor 등록 안 됨
- 30일 heartbeat 이력 없음
- 장애 자동 복구 검증 없음

필요 보강:

- 서비스 등록
- 재시작 정책
- 장애 카운터
- heartbeat 감시
- 장별 세션 라우팅

### 7. 모니터링/알림

판정: `degraded`

이번 보강:

- `config/alerts.json` 추가
- blocked/degraded/data_stale/reconciliation_drift 규칙 정의

아직 부족:

- 실제 알림 채널 미활성
- Telegram/email/Slack 등 전달 채널 없음
- 알림 실패 재시도 없음

### 8. 리스크 통제

판정: `ok`

현재 가능:

- 미수/신용 하드 차단
- 단일 주문 리스크 검사
- 펀드 레벨 리스크 리포트

- 보유 종목 수와 레버리지/인버스 합산 비중 검사

추가 고도화 대상:

- 실현/미실현 일중 손실 한도
- broker별 주문 제한, 호가 단위, 유동성/시장충격 모델
- 스트레스 시나리오 기반 주문 축소

## 최종 판정

Atlas Investment은 지금 당장 “글로벌 모든 투자를 수행하는 초거대 헤지펀드”도 아니고, “365일 24/7 완벽한 무인 자동화 실거래 시스템”도 아니다.

하지만 이번 보강으로 중요한 진전이 생겼다.

- 이제 프로그램 스스로 그 사실을 `blocked`로 판정한다.
- 부족 항목과 증거를 JSON 리포트로 남긴다.
- 데몬, 알림, 자동화 정책의 기본 골격이 생겼다.
- 실거래 차단 정책을 유지하면서 다음 고도화 순서를 명확히 했다.
