# 47. 전략 엔진 고도화 및 앙상블 검증 구현 기록

> 최신 기준(2026-06-01): Atlas Investment은 토스증권 공식 API 출시 전 안전한 PAPER/DRY_RUN 운용 OS입니다. 완성된 글로벌 헤지펀드 또는 실거래 봇으로 판정하지 않습니다. 실거래는 공식 API adapter 구현, read-only reconciliation, 30일 heartbeat, promotion evidence 통과 후에만 검토합니다.

## 1. 요청

사용자는 전략 레이어의 부족분을 전부 보강하라고 요청했다.

대상 부족분:

- `quant-portfolio` 매수 기준이 너무 보수적임
- 크로스섹션 전략이 진짜 universe ranking을 계산하지 않음
- QVM/캐리/이벤트 전략이 샘플 metadata 중심임
- 스캘핑/마켓메이킹이 일봉 시뮬레이션 수준임
- 검증 지표가 부족함
- 앙상블 포트폴리오 백테스트가 약함
- Market Regime Filter, True Cross-Sectional Momentum, Ensemble Threshold Calibration, Portfolio-Level Strategy Backtest, Risk Overlay가 필요함

## 3. Market Regime Filter

구현 파일:

- `src/atlas_investment/strategy/regime.py`

기능:

- benchmark daily candles로 시장 국면을 판단한다.
- trend: `bull`, `bear`, `sideways`, `unknown`
- volatility: `low`, `normal`, `high`, `unknown`
- 국면별 전체 노출 배수와 전략별 가중치 multiplier를 반환한다.

반영 방식:

- `quant-portfolio`에서 첫 benchmark symbol 기준으로 시장국면을 감지한다.
- bull에서는 momentum/trend 계열 가중치를 높인다.
- bear에서는 전체 exposure를 줄이고 low-vol/carry 계열 가중치를 높인다.
- high volatility에서는 전체 exposure를 추가 축소한다.

## 4. True Cross-Sectional Momentum

구현 파일:

- `src/atlas_investment/strategy/cross_sectional.py`

기능:

- universe 전체의 1개월, 3개월, 6개월, 12개월 수익률을 계산한다.
- 1개월은 단기 reversal을 고려해 음의 가중치로 반영한다.
- 3/6/12개월은 양의 모멘텀 가중치로 반영한다.
- 종목별 percentile, rank, score를 계산한다.
- 계산된 `momentum_rank`, `cross_sectional_momentum_score`, `cross_sectional_rank`, `cross_sectional_returns`를 asset metadata에 주입한다.

효과:

- `cross_sectional_momentum` 전략이 더 이상 단순 기본값에 의존하지 않는다.
- 현재 로드된 universe 안에서 상대 강도 랭킹을 사용한다.

## 5. Ensemble Threshold Calibration

수정 파일:

- `src/atlas_investment/portfolio/strategy_allocation.py`

기존 문제:

- buy 기준이 고정 62점이었다.
- 샘플/보수적 환경에서는 최고 후보가 55점대여도 모두 hold가 됐다.

수정:

- adaptive threshold를 추가했다.
- `buy_quantile=0.8`, `min_buy_score=54.0` 기본값을 사용한다.
- target weight가 있고, sell이 아니며, universe 상위 분위수에 속하는 후보는 buy로 승격한다.

효과:

- `quant-portfolio`가 후보를 만들고도 항상 0 buy가 되는 문제를 해소했다.
- 단, 아주 낮은 점수 후보를 억지로 buy하지 않도록 최소 점수 바닥은 유지한다.

## 6. Risk Overlay

구현 파일:

- `src/atlas_investment/portfolio/risk_overlay.py`

기능:

- 시장국면과 현재 drawdown을 기준으로 전체 gross exposure를 줄인다.
- bear/high volatility/drawdown 상태에서 신규 위험 노출을 줄인다.

반영:

- `quant-portfolio`는 risk overlay multiplier를 후보 target weight에 적용한다.
- `portfolio-optimizer`는 overlay 이후 후보를 받아 최적화한다.

## 7. QVM/캐리/이벤트 데이터 품질 게이트

수정 파일:

- `src/atlas_investment/cli.py`

기능:

- `quant-portfolio` 결과에 `factor_warnings`를 포함한다.
- 필수 팩터가 빠진 자산 수를 표시한다.
- 공식 factor data source가 없는 자산 수를 표시한다.

중요:

- 실제 PER/PBR/ROE/FCF margin/debt/EPS revision provider가 아직 없으므로, 샘플 metadata를 공식 데이터처럼 취급하지 않는다.
- 이 보강은 QVM을 더 정직하게 만든다. 실데이터 연결 전까지 QVM은 후보 연구용이다.

## 8. 전략 검증 지표 확장

수정 파일:

- `src/atlas_investment/backtest/validation.py`

추가 지표:

- Sharpe ratio
- Sortino ratio
- Calmar ratio
- Profit factor
- Turnover
- Exposure time
- Benchmark alpha
- Benchmark beta

효과:

- 단순 수익률/MDD/거래 수 기준보다 전략의 품질을 더 입체적으로 볼 수 있다.
- Sharpe가 음수이거나 profit factor가 1 미만이면 warning을 추가한다.

## 9. Portfolio-Level Ensemble Backtest

구현 파일:

- `src/atlas_investment/backtest/ensemble.py`

CLI:

- `ensemble-backtest`

기능:

- 여러 전략을 동시에 사용해 일정 간격으로 리밸런싱한다.
- 각 리밸런싱 시점에 cross-sectional rank를 다시 계산한다.
- market regime multiplier를 반영한다.
- ensemble allocation 결과를 target portfolio로 변환한다.
- 포트폴리오 equity curve, total return, MDD, average gross exposure, rebalance count를 산출한다.

주의:

- 현재는 sample/PAPER 수준의 daily close 기반 포트폴리오 백테스트다.
- 실전 승격 전에는 실제 survivorship-bias-free universe, 비용, 세금, 유동성, corporate action, 실시간 체결 모델이 필요하다.

## 10. 검증 결과

## 10-A. 글로벌 헤지펀드 스타일 전략군 추가 보강

르네상스, 브리지워터, AQR, Two Sigma, CTA/managed futures 계열에서 공개적으로 알려진 운용 원리를 직접 복제할 수는 없지만, 공개 가능한 범주의 제도권 전략 골격을 Atlas Investment 전략 레지스트리에 추가했다.

추가 파일/수정 파일:

- `src/atlas_investment/strategy/plugins.py`
- `src/atlas_investment/strategy/registry.py`
- `src/atlas_investment/portfolio/strategy_allocation.py`
- `src/atlas_investment/strategy/regime.py`
- `src/atlas_investment/cli.py`

추가 전략:

- `all_weather_risk_parity`: 주식, 채권, 원자재, 헤지 sleeve를 변동성 기준으로 조정하는 Bridgewater All Weather/Risk Parity 계열 자산배분 프록시.
- `macro_regime_allocation`: 가격 추세와 변동성 프록시로 리스크온/리스크오프를 나누고 성장/방어/헤지 sleeve를 전환하는 글로벌 매크로 프록시.
- `cta_diversified_trend`: 20/60/120일 추세와 변동성 타겟팅을 결합하는 CTA/managed futures 계열 분산 추세 전략.

연결 결과:

- 세 전략은 `all_strategies()` 레지스트리에 등록했다.
- `all_weather`, `risk_parity`, `global_macro`, `macro`, `cta`, `managed_futures` alias를 추가했다.
- `quant-portfolio`와 `ensemble-backtest` 기본 전략군에 세 전략을 포함했다.
- market regime multiplier에 세 전략을 포함해 하락장/고변동성장에서 방어 전략 비중이 올라가도록 조정했다.
- `DEFAULT_STRATEGY_WEIGHTS`를 멀티팩터, 모멘텀, 올웨더, 매크로, CTA, 저변동성 중심으로 재배분했다.

주의:

- 이 구현은 공개적으로 알려진 전략 원리를 Atlas Investment의 현재 데이터 구조에 맞춘 내부 전략 템플릿이다.
- 실제 Renaissance/Bridgewater/AQR/Two Sigma의 독점 모델, 대체데이터, 실행 엔진, 리서치 파이프라인을 복제한 것이 아니다.
- live 승격 전에는 실제 글로벌 ETF/선물/FX universe, survivorship-bias-free 데이터, 비용/세금/시장충격 모델이 필요하다.

## 11. 남은 한계

이번 구현으로 전략 엔진은 더 좋아졌지만, 다음은 여전히 외부 데이터/실전 인프라가 필요하다.

- 실제 factor provider: PER/PBR/ROE/FCF margin/debt/EPS revision
- analyst consensus와 revision history
- 실시간 order book, spread, 체결강도
- 스캘핑/마켓메이킹용 amend/cancel/fill stream
- survivorship-bias-free 글로벌 universe
- corporate action adjustment
- 실제 거래비용/세금/시장충격 모델
- benchmark/sector/factor exposure 데이터

따라서 스캘핑/마켓메이킹은 여전히 실전 전략이 아니라 simulation/candidate 레벨이다.

## 12. 결론

부족했던 전략 상위 레이어는 크게 보강됐다.

- 고정 buy threshold 문제 해결
- 진짜 cross-sectional ranking 추가
- market regime filter 추가
- risk overlay 추가
- QVM 데이터 품질 warning 추가
- 전략 검증 지표 확장
- 앙상블 포트폴리오 백테스트 추가

현재 결과는 “전략 수만 많은 상태”에서 “전략을 조합하고, 국면을 반영하고, 포트폴리오 단위로 검증하는 상태”로 한 단계 올라갔다.

다만 실거래 완성은 여전히 공식 API, 실시간 데이터, 실계좌 대사, 운용 증거가 필요하다.
