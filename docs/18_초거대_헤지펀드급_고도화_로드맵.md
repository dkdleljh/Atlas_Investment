# Atlas Investment 초거대 헤지펀드급 고도화 로드맵

> 최신 기준(2026-05-31): Atlas Investment은 토스증권 공식 API 출시 전 안전한 PAPER/DRY_RUN 운용 OS입니다. 완성된 글로벌 헤지펀드 또는 실거래 봇으로 판정하지 않습니다. 토스 플랫폼 범위는 KR/US 주식·ETF·채권·미국주식 옵션 중심이며, 직접 선물·현물 FX·직접 원자재 거래는 공식 지원 전까지 제외합니다. 실거래는 공식 API adapter 구현, read-only reconciliation, 30일 heartbeat, promotion evidence 통과 후에만 검토합니다.

작성일: 2026-05-30

## 목표

Atlas Investment의 장기 목표는 단일 자동매매 프로그램이 아니라, 한국장·미국장·외환·ETF·레버리지/인버스·퀀트 전략을 통합 운용하는 멀티에셋 헤지펀드 운영체제다.

핵심은 모든 투자를 다 하는 것이 아니라, 모든 투자 방식을 하나의 통제 체계 안에서 안전하게 다룰 수 있게 만드는 것이다.

## 최상위 원칙

1. 실거래보다 데이터와 리스크가 먼저다.
2. 전략보다 포트폴리오가 상위다.
3. 수익률보다 생존성이 먼저다.
4. 자동화보다 차단/중지/복구가 먼저다.
5. 모든 주문은 설명 가능해야 한다.
6. 모든 전략은 백테스트, 워크포워드, PAPER 검증을 거쳐야 한다.
7. 미수와 신용은 영구 금지다.
8. 토스증권 실주문은 공식 API 문서와 키가 확인되기 전까지 비활성이다.

## Phase 9: 실제 데이터 레이크

목표:

- 한국/미국/외환 데이터를 일관된 형식으로 저장

구현 항목:

- 한국 전체 종목 마스터 자동 갱신
- 미국 주식/ETF 심볼 마스터
- 한국 일봉/분봉 저장소
- 미국 일봉/분봉 저장소
- USD/KRW 환율 저장소
- 휴장일/거래시간 캘린더
- 거래정지/관리종목/상장폐지 상태
- 배당/액면분할/병합 보정
- 데이터 소스별 신뢰도 등급

CLI:

```bash
atlas-investment data-sync
atlas-investment data-audit --market KR
atlas-investment data-audit --market US
atlas-investment fx-sync
```

완료 기준:

- 샘플 데이터 없이 전체 유니버스 감사 가능
- 데이터 누락/중복/이상가격 자동 탐지
- 리포트로 데이터 품질 점수 확인 가능

## 다음 개발 추천

바로 다음 개발은 다음 3개가 가장 효율적이다.

1. `data-sync` 명령 추가
   - 한국/미국/외환 데이터를 실제 저장소로 동기화

2. `strategy-lab` 명령 추가
   - 여러 전략을 여러 종목에 돌려 랭킹과 안정성 점수 생성
