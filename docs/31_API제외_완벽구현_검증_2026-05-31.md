# 토스 공식 API 제외 완벽 구현 여부 검증

> 최신 기준(2026-05-31): Atlas Investment은 토스증권 공식 API 출시 전 안전한 PAPER/DRY_RUN 운용 OS입니다. 완성된 글로벌 헤지펀드 또는 실거래 봇으로 판정하지 않습니다. 토스 플랫폼 범위는 KR/US 주식·ETF·채권·미국주식 옵션 중심이며, 직접 선물·현물 FX·직접 원자재 거래는 공식 지원 전까지 제외합니다. 실거래는 공식 API adapter 구현, read-only reconciliation, 30일 heartbeat, promotion evidence 통과 후에만 검토합니다.

작성일: 2026-05-31

## 질문

토스증권 공식 API 부분을 제외하면 Atlas Investment이 전부 완벽하게 구현되었는지, 기존 문서와 실제 프로그램을 대조해 검증한다.

## 결론

**아니다. 토스증권 공식 API를 제외해도 전부 완벽하게 구현된 상태는 아니다.**

현재 상태는 다음과 같이 정리하는 것이 정확하다.

- 개발/연구용 운용 OS: `작동`
- PAPER/DRY_RUN 안전 골격: `작동`
- 핵심 리스크 게이트: `상당 부분 구현`
- 문서화/감사 명령: `작동`
- 글로벌 헤지펀드급 전체 구현: `미완`
- 365일 24x7 완전 무인 운영: `미완`
- 기관급 실데이터/글로벌 유니버스/다자산군 운용: `미완`

```bash
.venv/bin/python -m unittest discover -s tests
```

## API 제외 후에도 남는 핵심 미완성 항목

### 1. 글로벌 유니버스

현재 readiness 감사 결과:

```text
16 tradable assets across markets=['KR', 'US']
```

미완성:

- KRX 전체 종목
- 미국 전체 종목/ETF
- 유럽, 일본, 홍콩, 중국, 신흥국
- 상장폐지/거래정지/심볼 변경 이력
- survivorship bias 제거

### 2. 자산군 커버리지

현재:

```text
stock, etf
```

미완성:

- bond
- future
- option
- FX
- commodity

토스 공식 API를 제외하더라도, 글로벌 헤지펀드 수준을 주장하려면 이 자산군 모델과 리스크/회계/체결 규칙이 필요하다.

### 3. 기관급 데이터

현재:

- sample OHLCV
- yfinance/hybrid fallback
- 작은 데이터 레이크

미완성:

- 유료/공식 데이터 공급원
- 실시간 호가/체결 데이터
- 분할/배당/권리락 조정
- 상장폐지 포함 과거 데이터
- 데이터 SLA와 failover

### 4. 전략 검증

검증 결과:

```text
strategy-validate: degraded
warning_count: 2
```

경고:

- 워크포워드 양수 수익 fold 비율 낮음
- 일부 검증 구간 거래 없음

이는 프로그램 오류가 아니라, 현재 전략이 기관급 실전 운용에 충분히 검증됐다고 볼 수 없다는 뜻이다.

### 5. 현재 mock 포트폴리오 리스크

검증 결과:

```text
risk-report: blocked
VOO 단일 종목 비중이 한도를 초과했습니다.
```

리스크 엔진은 작동하지만, 현재 기본 mock 포트폴리오는 정책 한도를 위반한다. 완벽한 운영 상태라면 기본 포트폴리오 fixture도 정책에 맞아야 한다.

### 6. 24x7 무인 운영

현재:

- daemon script 있음
- automation policy 있음
- dashboard 있음

미완성:

- systemd/supervisor 실등록
- restart policy 검증
- heartbeat 장기 이력
- 알림 채널 활성화
- 장애 자동 복구 리허설

### 7. 알림/관제

현재:

- `config/alerts.json` 있음
- dashboard 생성 가능

미완성:

- 실제 Telegram/email/Slack 알림 채널
- 알림 실패 재시도
- blocked/degraded 상태의 운영자 호출
- reconciliation drift 알림

### 8. 거버넌스

검증 결과:

```text
governance-report: blocked
live_promotion: blocked
```

토스 API 제외와 관계없이, 실거래 전환 승인 기록과 장기 운용 증빙은 아직 없다.

## 완성된 것으로 볼 수 있는 영역

다음은 현재 코드와 테스트 기준으로 동작한다.

- DRY_RUN/PAPER 실행 루프
- 단일 주문 리스크 검사
- batch 주문 리스크 검사
- 미수/신용 하드 차단
- 레버리지/인버스 별도 한도
- 백테스트 다음 봉 체결
- 비용 정책 기본 반영
- 주문 상태 머신
- 데이터 품질 검사
- 샘플 데이터 동기화
- HTML dashboard 생성
- readiness/healthcheck/audit CLI
- 문서화 체계

## 최종 판정

Atlas Investment은 토스 공식 API 제외 기준으로도 **완벽한 글로벌 헤지펀드 완성품은 아니다.**

정확한 표현은 다음이다.

> Atlas Investment은 토스 공식 API 출시 전까지 개발 가능한 핵심 안전장치와 운용 OS 골격을 대부분 갖춘 상태다. 그러나 글로벌 전체 투자, 기관급 데이터, 다자산군 운용, 24x7 supervisor, 알림/관제, 장기 검증, live promotion 증빙은 아직 완성되지 않았다.

따라서 다음 단계는 토스 API 연결 대기와 별개로 아래를 진행해야 한다.

1. 전체 시장 instrument master 구축
2. survivorship-bias-free 데이터 공급원 연결
3. 기본 mock 포트폴리오를 리스크 정책에 맞게 수정
4. 전략 검증에서 `degraded` 경고가 사라질 만큼 전략/데이터/기간 보강
5. systemd 또는 supervisor 등록
6. 실제 알림 채널 연결
7. 30영업일 DRY_RUN/PAPER 운용 증빙 축적
8. read-only reconciliation 장기 통과 기록 축적
