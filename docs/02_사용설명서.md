# Atlas Investment 사용설명서

> 최신 기준(2026-05-31): Atlas Investment은 토스증권 공식 API 출시 전 안전한 PAPER/DRY_RUN 운용 OS입니다. 완성된 글로벌 헤지펀드 또는 실거래 봇으로 판정하지 않습니다. 토스 플랫폼 범위는 KR/US 주식·ETF·채권·미국주식 옵션 중심이며, 직접 선물·현물 FX·직접 원자재 거래는 공식 지원 전까지 제외합니다. 실거래는 공식 API adapter 구현, read-only reconciliation, 30일 heartbeat, promotion evidence 통과 후에만 검토합니다.

## 1. 프로그램 위치

프로그램은 바탕화면의 아래 폴더에 있습니다.

```bash
/home/zenith/Desktop/Atlas_Investment
```

## 2. 현재 버전에서 할 수 있는 일

현재 버전은 실거래 프로그램이 아니라, 실거래 전 검증용 엔진입니다.

가능한 기능:

- 샘플 한국/미국 종목을 불러옵니다.
- 종목별 매수/보유/매도 신호를 만듭니다.
- 전략 플러그인으로 여러 전략을 선택할 수 있습니다.
- 샘플 OHLCV 데이터로 백테스트를 실행할 수 있습니다.
- 백테스트 결과를 JSON 파일로 저장합니다.
- 투자위원회 방식으로 판단합니다.
- 주문 후보를 만듭니다.
- 리스크 정책을 검사합니다.
- PAPER 모드에서는 가상 체결을 기록합니다.
- 실행 결과를 `data/journals/atlas_investment.jsonl`에 저장합니다.

## 3. 실행 방법

### 3.1 PAPER 모드 실행

터미널에서 아래 명령을 실행합니다.

```bash
cd /home/zenith/Desktop/Atlas_Investment
PYTHONPATH=src python3 -m atlas_investment.cli --mode paper --once
```

`paper` 대신 `dry_run`을 쓰면 가상 체결 없이 판단만 기록합니다.

```bash
PYTHONPATH=src python3 -m atlas_investment.cli --mode dry_run --once
```

### 3.2 백테스트 실행

백테스트는 특정 종목과 특정 전략을 과거 데이터로 검증하는 기능입니다. 현재는 샘플 OHLCV 데이터를 자동 생성해서 사용합니다.

삼성전자 샘플 백테스트:

```bash
PYTHONPATH=src python3 -m atlas_investment.cli backtest --symbol 005930 --strategy moving_average_cross
```

애플 샘플 백테스트:

```bash
PYTHONPATH=src python3 -m atlas_investment.cli backtest --symbol AAPL --strategy breakout_momentum
```

RSI 평균회귀 전략:

```bash
PYTHONPATH=src python3 -m atlas_investment.cli backtest --symbol TSLA --strategy rsi_mean_reversion
```

결과 파일은 아래 폴더에 저장됩니다.

```bash
data/backtests/
```

### 3.3 사용할 수 있는 전략 이름

현재 사용할 수 있는 백테스트 전략은 다음과 같습니다.

- `moving_average_cross`: 20일/60일 이동평균 기반 중기 추세 전략
- `rsi_mean_reversion`: RSI 과매도/과열 기반 단기 평균회귀 전략
- `breakout_momentum`: 60일 신고가 돌파 기반 스윙 모멘텀 전략

## 4. 설정 파일

### 4.1 리스크 정책

위치:

```bash
config/risk_policy.json
```

중요 설정:

```json
{
  "allow_margin_trading": false,
  "allow_credit_trading": false,
  "allow_leveraged_inverse": true
}
```

이 설정은 주인님이 정한 정책입니다.

- 미수는 절대 금지
- 신용은 절대 금지
- 레버리지/인버스 종목은 허용

### 4.2 전략 설정

위치:

```bash
config/strategy.json
```

주문 후보 금액, 목표 비중, 대상 시장 등을 정합니다.

## 5. 실행 결과 확인

실행 후 감사 로그는 아래 파일에 쌓입니다.

```bash
data/journals/atlas_investment.jsonl
```

최근 로그를 보려면:

```bash
tail -n 5 data/journals/atlas_investment.jsonl
```

백테스트 결과는 아래처럼 확인할 수 있습니다.

```bash
ls data/backtests
```

결과 파일에는 다음 정보가 들어갑니다.

- 전략 이름
- 종목 코드
- 초기 현금
- 최종 평가금액
- 총수익률
- 최대 낙폭
- 거래 횟수
- 승률
- 거래 내역
- 일자별 평가금액

## 6. 실거래 연결 전 주의사항

토스증권 Open API가 아직 공개되지 않았기 때문에 실주문 기능은 구현하지 않았습니다.

토스증권 API 문서가 공개되면 다음 정보가 필요합니다.

- REST 기본 URL
- 인증 방식
- API 키 발급 방식
- 주문 제출 엔드포인트
- 주문 취소/정정 엔드포인트
- 계좌 조회 엔드포인트
- WebSocket 접속 주소
- 실시간 시세 메시지 형식
- 주문/체결 이벤트 메시지 형식
- 호출 제한
- 오류 코드

이 정보가 들어온 뒤에만 `TossLiveBroker`를 구현합니다.

## 7. 가장 중요한 운영 원칙

Atlas Investment은 수익을 내기 전에 먼저 사고를 막아야 합니다.

항상 지켜야 할 원칙:

- 미수/신용 금지
- 킬스위치 우선
- 실거래 전 PAPER 검증
- 주문 전 리스크 검사 필수
- 모든 판단과 주문 기록
- API 장애 시 신규 주문 중단
