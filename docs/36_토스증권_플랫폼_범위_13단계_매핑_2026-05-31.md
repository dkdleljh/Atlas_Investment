# 토스증권 플랫폼 범위와 13단계 매핑

> 최신 기준(2026-05-31): Atlas Investment은 토스증권 공식 API 출시 전 안전한 PAPER/DRY_RUN 운용 OS입니다. 완성된 글로벌 헤지펀드 또는 실거래 봇으로 판정하지 않습니다. 토스 플랫폼 범위는 KR/US 주식·ETF·채권·미국주식 옵션 중심이며, 직접 선물·현물 FX·직접 원자재 거래는 공식 지원 전까지 제외합니다. 실거래는 공식 API adapter 구현, read-only reconciliation, 30일 heartbeat, promotion evidence 통과 후에만 검토합니다.

작성일: 2026-05-31

## 질문

완성된 글로벌 헤지펀드와 토스 API 출시 후 실거래 동작을 `true`로 만들기 위한 13단계가 토스증권 API와 관련이 있는지 확인하고, 토스증권 플랫폼에 맞춘다.

## 확인한 공개 정보

토스증권 공식 투자상품 페이지는 주식, ETF, 채권, 미국주식 옵션을 투자상품 표면으로 제시한다.

추가 공개 자료 기준:

- 토스증권은 미국 주식 거래 가능 종목을 10,000여 개 수준으로 확대한 바 있다.
- 토스증권은 해외채권 서비스를 출시했다.
- 토스증권은 미국주식 거래 시간을 확대해 사실상 장시간 거래 환경을 제공한다.

단, 공개 앱/상품 표면과 향후 공식 Open API 지원 범위는 다를 수 있다. 최종 자동매매 가능 자산은 공식 API 문서가 우선한다.

## 토스증권 플랫폼에 맞춘 자산군 범위

Atlas Investment의 Toss 프로필:

```text
config/toss_platform_profile.json
```

지원 가정:

```text
markets: KR, US
asset_kinds: stock, etf, bond, option
```

조건부/제외:

```text
future: 제외. 토스 공식 API가 명시 지원하기 전까지 직접 선물 주문 금지
fx: 제외. 직접 spot FX 거래가 아니라 환전/현금/통화 노출 회계로 처리
commodity: 제외. 직접 원자재 거래가 아니라 토스 지원 ETF로만 노출
etn: 공식 tradable universe가 명시할 때만 허용
```

## 13단계와 토스 API 관련성

### 1. 글로벌 데이터 provider 선정/계약

토스 API 관련성: 간접 관련

토스 주문 가능 universe와 가격/호가 데이터가 필요하다. 하지만 기관급 백테스트용 survivorship-bias-free 데이터는 토스 API만으로 충분하지 않을 수 있다.

토스 맞춤:

- KR/US 주식/ETF/채권/미국주식 옵션 데이터 공급원 우선
- 선물/직접 FX/직접 원자재 데이터는 Toss route 범위에서 제외

### 2. instrument master 구축

토스 API 관련성: 직접 관련

자동 주문은 토스에서 실제 주문 가능한 종목만 universe에 들어가야 한다.

토스 맞춤:

- KR 주식/ETF
- US 주식/ETF
- Toss 지원 해외채권
- Toss 지원 미국주식 옵션
- Toss 지원 여부, 최소 주문수량, 주문 가능 시간, 주문 타입, 통화, 세금, 거래정지 상태 포함

### 3. data_entitlements.json 실제 provider로 채움

토스 API 관련성: 간접 관련

데이터 권리와 API 권리는 분리된다.

토스 맞춤:

- 토스 API가 제공하는 실시간 데이터 권리
- 별도 licensed historical data provider 권리
- survivorship-bias-free 여부 명시

### 4. 다자산군 universe/계약 규칙 구축

토스 API 관련성: 직접 관련

단, 토스 지원 자산군으로 제한한다.

토스 맞춤:

- stock
- ETF
- bond
- US stock option

제외:

- direct futures
- direct spot FX
- direct commodities

### 5. systemd daemon 30일 운영

토스 API 관련성: 무관하지만 실운영 필수

토스와 관계없이 무인 운영 증빙이 필요하다.

현재:

```text
systemd enabled: true
systemd active: true
heartbeat days: 1
```

### 6. DRY_RUN 30영업일 기록

토스 API 관련성: 간접 관련

토스 주문 가능 universe와 같은 제약으로 DRY_RUN을 돌려야 한다.

### 7. PAPER 30영업일 기록

토스 API 관련성: 간접 관련

토스 주문 가능 시간, 주문 타입, 호가 단위, 체결 제약을 paper broker가 반영해야 한다.

### 8. read-only reconciliation 10거래일 통과

토스 API 관련성: 직접 관련

실계좌 잔고/포지션/주문/체결 스냅샷이 필요하다. 현재 `tossctl` 또는 공식 read-only API가 없어서 blocked다.

### 9. 토스 공식 API 출시 대기

토스 API 관련성: 직접 관련

이 단계 전까지 live order는 차단한다.

### 10. TossLiveBroker 구현

토스 API 관련성: 직접 관련

공식 문서 기반으로 다음을 구현해야 한다.

- 인증
- 계좌 조회
- 잔고 조회
- 포지션 조회
- 주문 가능 금액 조회
- 주문 제출
- 정정
- 취소
- 미체결 조회
- 체결 조회
- WebSocket 시세/체결 이벤트

### 11. 소액 실주문 검증

토스 API 관련성: 직접 관련

공식 API adapter 구현 후 최소 금액으로 검증한다.

### 12. live promotion approval 작성

토스 API 관련성: 간접 관련

기술적으로는 governance 영역이지만, 토스 API adapter와 reconciliation 검증 결과가 승인 근거가 된다.

### 13. hedgefund-readiness 전체 ok 확인

토스 API 관련성: 직접/간접 모두 포함

토스 API readiness, 데이터, universe, daemon, promotion evidence가 모두 통과해야 한다.

## 최종 결론

13단계 중 토스 API와 직접 관련된 것은 2, 4, 8, 9, 10, 11, 13이다. 간접 관련은 1, 3, 6, 7, 12다. 5번은 토스 API와 무관하지만 무인 운영 필수 조건이다.

Atlas Investment은 앞으로 글로벌 헤지펀드 범위를 “모든 자산을 아무 브로커로나 거래”가 아니라, **토스증권에서 공식 지원하는 자산군과 시장을 중심으로 운용**하도록 맞춘다.

토스증권 기준 목표 범위:

```text
국내/미국 주식
국내/미국 ETF
토스 지원 채권
토스 지원 미국주식 옵션
원자재는 ETF로만
FX는 환전/현금/통화노출 회계로만
선물은 공식 지원 전까지 제외
```
