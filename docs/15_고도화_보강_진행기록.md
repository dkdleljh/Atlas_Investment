# Atlas Investment 고도화 보강 진행 기록

> 최신 기준(2026-05-31): Atlas Investment은 토스증권 공식 API 출시 전 안전한 PAPER/DRY_RUN 운용 OS입니다. 완성된 글로벌 헤지펀드 또는 실거래 봇으로 판정하지 않습니다. 토스 플랫폼 범위는 KR/US 주식·ETF·채권·미국주식 옵션 중심이며, 직접 선물·현물 FX·직접 원자재 거래는 공식 지원 전까지 제외합니다. 실거래는 공식 API adapter 구현, read-only reconciliation, 30일 heartbeat, promotion evidence 통과 후에만 검토합니다.

작성일: 2026-05-30

## 목적

`14_고도화_우선순위_제안.md`에서 정리한 보강 항목을 문서에만 두지 않고, 실제 코드 골격과 CLI 명령, 테스트로 연결했습니다.

이번 보강도 실거래 주문을 만들기 위한 작업이 아닙니다. 토스증권 공식 API 문서와 키가 공개되기 전까지 `LIVE_AUTO`는 계속 차단 상태여야 합니다.

## 1. 실제 데이터 레이어 보강

추가한 내용:

- 종목 마스터 모델
- 샘플 유니버스를 종목 마스터 JSON으로 저장
- 저장된 종목 마스터 재로드
- 거래 가능 종목 변환
- OHLCV 품질 검사
- 데이터 공급자 어댑터 골격

관련 파일:

- `src/atlas_investment/data/instruments.py`
- `src/atlas_investment/data/quality.py`
- `src/atlas_investment/data/vendors.py`

실행 명령:

```bash
PYTHONPATH=src python3 -m atlas_investment.cli data-audit
```

생성 파일:

- `data/instruments/instrument_master.json`
- `data/reports/data_audit.json`

## 남은 과제

이번 보강으로 Atlas Investment은 샘플 기반 기관급 운용 플랫폼 골격이 더 촘촘해졌습니다. 다만 아래는 여전히 실제 외부 연결이 필요합니다.

- 실제 한국/미국 전체 종목 마스터
- 실제 일봉/분봉/환율 데이터 공급원
- 공식 한국/미국 휴장일 캘린더
- 상시 실행 데몬
- 장애 복구 자동화
- 알림/보고 채널
- 토스증권 공식 REST/WebSocket API 구현
- 실계좌 조회, 실시간 시세, 실주문, 정정, 취소, 체결 이벤트 처리
