## 2. 현재 Atlas Investment의 위치

Atlas Investment은 현재 다음 성격의 프로그램이다.

- DRY_RUN/PAPER 기반 자동 운용 연구 시스템
- 한국/미국 주식·ETF 중심의 전략 연구소
- 토스증권 공식 API 출시 전 live broker를 비워둔 안전한 운용 OS
- 글로벌 헤지펀드식 운용에 필요한 전략, 리스크, 집행, 감사, 문서화를 단계적으로 쌓는 코드베이스

Atlas Investment은 아직 다음이 아니다.

- 완전 무인 live hedge fund
- 공식 주문 API가 붙은 실계좌 자동매매 시스템
- 30영업일 이상 무인 운영 증거를 확보한 live promotion 완료 시스템
- 라이선스 있는 글로벌 데이터와 전체 instrument master를 갖춘 기관급 글로벌 트레이딩 플랫폼

## 3. 최신 구조 지도

### 3.1 CLI와 실행 진입점

중심 진입점:

- `src/atlas_investment/cli.py`
- console script: `atlas-investment`

핵심 명령군:

- 기본 운용: `run`, `healthcheck`, `readiness`, `ops-plan`, `ops-report`
- 데이터: `data-sync`, `daily-data-refresh`, `data-audit`, `data-snapshot-audit`, `data-entitlements`
- 전략: `backtest`, `compare`, `strategy-lab`, `strategy-validate`, `strategy-readiness`
- 퀀트 포트폴리오: `quant-portfolio`, `strategy-allocation`, `portfolio-optimizer`
- 리스크/회계: `risk-report`, `fund-risk`, `accounting-ledger`, `cost-report`, `fx-exposure`, `fx-overlay`
- 집행: `execution-sim`, `algo-execution-plan`, `child-order-sim`, `order-state-smoke`
- 브로커/토스 준비: `toss-platform-fit`, `toss-readonly-status`, `toss-readonly-sync`, `reconciliation-check`
- 무인 운영 감사: `hedgefund-readiness`, `global-gap-audit`, `heartbeat-record`, `heartbeat-audit`, `promotion-evidence`, `promotion-evidence-record`

### 3.2 전략과 리서치

현재 전략 레지스트리는 21개 전략을 포함한다.

- 기본 추세/모멘텀: `moving_average_cross`, `breakout_momentum`, `long_term_trend`, `swing_momentum`
- 단기/평균회귀: `rsi_mean_reversion`, `volatility_breakout`, `stat_arb_mean_reversion`
- 팩터/퀀트: `factor_quality`, `multifactor_qvm`, `shareholder_yield_carry`, `low_vol_defensive`
- 헤지펀드 스타일: `time_series_momentum`, `cross_sectional_momentum`, `equity_long_short_quality`
- 리밸런싱/오버레이: `etf_rebalance`, `fx_overlay_signal`, `sector_regime_rotation`
- 이벤트/공시: `event_disclosure_watch`, `earnings_revision_event`
- 초단타/시장조성 후보: `scalping_simulation`, `liquidity_market_making_simulation`

중요한 제한:

- 초단타, 호가창 스캘핑, 시장조성은 실시간 호가·체결·정정/취소가 없으면 실거래로 승격하지 않는다.
- 롱숏/숏 전략은 공매도, 대차, 규제, 브로커 지원, 동시 체결 리스크가 해결되기 전까지 live 주문을 금지한다.
- ML/RL은 아직 core alpha가 아니다. feature store, model registry, drift monitoring, rollback이 먼저다.

### 3.3 포트폴리오와 리스크

현재 가능한 것:

- 전략 앙상블 기반 후보 생성
- 종목 최대 비중 제한
- 섹터 최대 비중 제한
- 리스크 패리티, 역변동성, 동일가중, 목표변동성 기반 최적화
- gross exposure 제한
- ADV 기반 capacity notional 추정
- USD/KRW 노출과 주문금액 정규화
- drawdown, VaR, 집중도, 상관관계 기반 리스크 리포트 골격

아직 더 필요한 것:

- 공분산 shrinkage
- factor neutrality
- beta neutrality
- currency hedge ratio 최적화
- turnover constraint
- tax-aware rebalancing
- 시장충격 모델
- 실시간 포지션·주문·체결 통합 리스크

### 3.4 집행과 주문 상태

현재 가능한 것:

- DRY_RUN 주문 후보 생성
- PAPER 가상 체결
- 주문 상태 머신 기록
- TWAP/VWAP/POV 상위 집행 계획
- PAPER child-order lifecycle 시뮬레이션
- LIVE_AUTO 명시 차단

아직 더 필요한 것:

- 공식 브로커 주문 adapter
- 실시간 order/fill stream
- partial fill 실계좌 반영
- cancel/replace
- 주문 거절/중복/지연 방지
- broker disconnect recovery
- kill switch와 market access control의 실거래 연결

### 3.5 운영 감사와 승격 증거

현재 가능한 것:

- `hedgefund-readiness`로 전체 실거래 준비도 점검
- `global-gap-audit`로 내부 구현 blocker와 외부 의존 blocker 분리
- `heartbeat-record`, `heartbeat-audit`로 daemon 운영 증거 추적
- `promotion-evidence`, `promotion-evidence-record`로 DRY_RUN/PAPER/reconciliation/small_order 증거 추적
- `reconciliation-check`로 내부 장부와 브로커 스냅샷 차이를 감사

중요 정책:

- `promotion-evidence-record`는 `status=ok`인 실제 증거만 승격 일수로 센다.
- smoke-test, blocked, degraded 기록은 증거 파일에 남길 수 있지만 승격 조건으로 세지 않는다.
- read-only broker snapshot이 없으면 reconciliation은 통과로 표시하지 않는다.
- heartbeat가 30일 이상 쌓이기 전까지 무인 운영 완료로 표시하지 않는다.

## 4. 최신 명령어 빠른 점검

문서와 코드의 현재 상태를 확인할 때는 아래 순서로 실행한다.

```bash
cd /home/zenith/Desktop/Atlas_Investment
.venv/bin/python -m compileall -q src tests
.venv/bin/python -m unittest discover -s tests -q
.venv/bin/python -m pip check
.venv/bin/python -m atlas_investment.cli hedgefund-readiness
.venv/bin/python -m atlas_investment.cli global-gap-audit
.venv/bin/python -m atlas_investment.cli strategy-lab --max-symbols 4 --days 180
.venv/bin/python -m atlas_investment.cli quant-portfolio --max-symbols 8 --days 220
.venv/bin/python -m atlas_investment.cli portfolio-optimizer --max-symbols 6 --days 180 --optimizer-method risk_parity
.venv/bin/python -m atlas_investment.cli child-order-sim --mode paper --algorithm vwap --symbol 005930 --slices 4 --limit 8
.venv/bin/python -m atlas_investment.cli promotion-evidence-record --evidence-kind dry_run --status blocked --source smoke-test
systemctl --user is-active atlas-investment.service
```

`promotion-evidence-record --status blocked`는 승격 증거를 만들기 위한 명령이 아니다. blocked 결과가 승격 일수에 더해지지 않는지 확인하는 안전한 smoke 명령이다. 실제 운용 증거는 daemon 또는 사람이 확인한 실제 `ok` 결과만 기록해야 한다.
