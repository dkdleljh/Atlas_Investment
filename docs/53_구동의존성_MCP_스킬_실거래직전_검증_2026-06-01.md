# 구동 의존성, MCP, 스킬, 실거래 직전 검증

작성 시각: 2026-06-01 KST

## 결론

Atlas Investment은 현재 공식 토스증권 API가 공개되기 전 단계에서 `DRY_RUN`, `PAPER`, 백테스트, 리스크/운영 감사, 데이터 갱신, 리포트 생성까지 구동 가능하다.

실거래 자동 주문은 여전히 차단이 정상이다. 차단 사유는 코드 실패가 아니라 토스증권 공식 주문/계좌/체결 API 문서와 키, 공식 브로커 스냅샷, 실운용 증거가 아직 없기 때문이다.

## 설치된 구동 의존성

`pyproject.toml` 기준 editable install을 다시 수행했다.

```text
python -m pip install -e .
=> Successfully installed atlas-investment-0.1.0
```

설치/확인된 핵심 패키지:

- `numpy>=1.24`
- `pandas>=2.0`
- `pygount>=3.2`
- `requests>=2.31`
- `yfinance>=0.2.40`

Node/npm은 MCP/운영 보조 점검을 위해 사용 가능하지만, 프로젝트 의존성으로 토스 관련 npm 패키지는 두지 않는다.

```text
node => v26.2.0
npm => 11.16.0
npm ls -g toss-securities --depth=0 => empty
```

프로젝트 루트에는 다음 항목이 없어야 한다.

```text
package.json
package-lock.json
node_modules
```

확인 결과 모두 존재하지 않는다.

## 실거래 직전 구동 검증

정적/단위 검증:

```text
python -m compileall -q src tests => OK
python -m unittest discover -s tests => Ran 80 tests, OK
pip check => No broken requirements found.
```

콘솔 엔트리포인트:

```text
.venv/bin/atlas-investment integration-check => overall_status=ok
```

주의: 현재 셸 PATH에는 `.venv/bin`이 자동 포함되어 있지 않다. 따라서 bare `atlas-investment`이 아니라 `.venv/bin/atlas-investment` 또는 `.venv/bin/python -m atlas_investment.cli`로 실행한다.

핵심 운영 명령:

```text
healthcheck => overall_status=ok
daily-data-refresh --vendor sample --max-symbols 4 --days 120 => status=ok, synced=5
data-audit => overall_status=ok
ops-report => status=ok
dashboard-html => status=ok
```

전략/백테스트/고도화 명령:

```text
quant-portfolio --max-symbols 8 --days 260
=> status=ok, signal_count=69, candidate_count=8, buy_count=3

ensemble-backtest --max-symbols 6 --days 180
=> status=ok, total_return_pct=-0.39, max_drawdown_pct=-0.7216, rebalance_count=5

advanced-internal-upgrade
=> status=ok, blocked=[]
```

토스 플랫폼/공식 API 대기:

```text
toss-platform-fit => status=ok
phase20-audit => overall_status=blocked
hedgefund-readiness => overall_status=blocked
global-gap-audit => code_possible_blockers=0, external_blockers=19
reconciliation-check => status=blocked
```

위 blocked는 정상이다. 공식 토스 계좌/포지션/주문/체결 스냅샷과 공식 주문 API가 없기 때문에 실거래 승격이 차단된다.

## 공식 API 공개 후 필요한 연결

공식 API가 공개되면 아래 환경변수를 설정하고 `TossLiveBroker`에 공식 adapter만 연결한다.

```text
TOSS_API_DOCS_URL
TOSS_API_REST_BASE_URL
TOSS_API_WEBSOCKET_URL
TOSS_API_APP_KEY
TOSS_API_APP_SECRET
TOSS_API_ACCOUNT_ID
```

그 다음 공식 스냅샷 adapter가 아래 경로를 생성해야 한다.

```text
data/official_broker_snapshots/toss/account.json
data/official_broker_snapshots/toss/account_summary.json
data/official_broker_snapshots/toss/positions.json
data/official_broker_snapshots/toss/open_orders.json
data/official_broker_snapshots/toss/fills.json
```

최소 10거래일 reconciliation 무차이, DRY_RUN/PAPER 증거, 소액 수동 승인, promotion evidence가 있어야 LIVE_AUTO 승격을 검토할 수 있다.
