## 2. ML/AI 전략 조사 요약

공개 자료 기준으로 ML/AI는 퀀트 운용에서 다음 방식으로 쓰인다.

- 머신러닝 기반 asset pricing: 선형모형보다 더 복잡한 비선형 상호작용을 포착하기 위해 tree, boosting, random forest, neural network 등이 연구된다.
- Two Sigma류 데이터 과학 운용: 대규모 구조/비구조 데이터, 과학적 투자 프로세스, 머신러닝 인사이트를 alpha research에 활용한다.
- 실무상 핵심 리스크: 데이터 누수, 과최적화, regime shift, 거래비용 반영 누락, 모델 설명가능성 부족.

참고한 공개 출처:

- Two Sigma Investment Management: https://www.twosigma.com/businesses/investment-management/
- AQR, `Empirical Asset Pricing via Machine Learning`: https://www.aqr.com/insights/research/journal-article/empirical-asset-pricing-via-machine-learning
- Review of Financial Studies, Gu/Kelly/Xiu, `Empirical Asset Pricing via Machine Learning`: https://academic.oup.com/rfs/article/33/5/2223/5758276

프로젝트 내부 확인 결과:

- 기존에는 ML/AI 전용 전략 플러그인이 없었다.
- 이번 작업에서 `ml_alpha_score` 전략을 추가했다.
- 외부 ML 패키지 의존 없이 momentum, volatility, quality, value, revision의 비선형 interaction을 쓰는 deterministic ML-style alpha score로 구현했다.
- 실제 neural network/boosting 모델 학습은 외부 데이터 권리와 훈련 데이터셋이 붙은 뒤 확장해야 한다.

## 3. 구현 요약

### 3.1 전략 파라미터 자동 보정

추가 파일:

- `src/atlas_investment/strategy/auto_tune.py`

기능:

- `StrategyParameterTuner`
- walk-forward validation 결과를 기반으로 `score_floor`, `target_scale`, `drawdown_penalty` 후보를 grid 탐색한다.
- median return, worst return, Sharpe, warning count를 반영해 최적 overlay parameter를 추천한다.
- 파라미터별 점수 분산이 크면 과최적화 경고를 낸다.

### 3.2 앙상블 메타 모델

추가 파일:

- `src/atlas_investment/portfolio/meta_allocator.py`

기능:

- `MetaStrategyAllocator`
- 전략 검증 리포트의 Sharpe, Sortino, profit factor, alpha, positive fold ratio, drawdown, warning count를 점수화한다.
- 전략별 동적 meta weight를 산출한다.
- 단일 전략 집중도가 높으면 경고한다.

### 3.3 거래비용/시장충격 모델

추가 파일:

- `src/atlas_investment/backtest/realistic.py`

기능:

- `MarketImpactCostModel`
- fee, spread proxy, slippage, square-root market impact, tax, ADV participation을 계산한다.
- ADV 10% 초과와 높은 spread proxy를 경고한다.

### 3.4 포트폴리오 리스크 고도화

추가 파일:

- `src/atlas_investment/risk/advanced.py`

기능:

- `AdvancedPortfolioRiskEngine`
- CVaR/expected shortfall, volatility target multiplier, correlation shock loss, sector exposure, FX exposure를 산출한다.
- tail risk, 변동성 초과, 섹터 집중을 경고한다.

### 3.5 전략별 승격/폐기 자동화

추가 파일:

- `src/atlas_investment/strategy/lifecycle.py`

기능:

- `StrategyLifecycleManager`
- 전략 검증 리포트를 바탕으로 `promote_candidate`, `paper_only`, `lab`, `quarantine` 상태를 결정한다.
- Sharpe, profit factor, positive fold ratio, overfit warning을 기준으로 weight multiplier를 정한다.

### 3.6 데이터 품질 방어 레이어

추가 파일:

- `src/atlas_investment/data/defense.py`

기능:

- `DataDefenseLayer`
- 기존 OHLCV 품질 검사에 stale data, split-like jump, volume anomaly 검사를 추가했다.
- 전략 입력 전 blocked/degraded/ok 상태를 판단한다.

### 3.7 백테스트 엔진 현실화

수정 파일:

- `src/atlas_investment/backtest/ensemble.py`

기능:

- 앙상블 포트폴리오 백테스트에 리밸런싱 비용, 시장충격, 평균 cost bps, 부분체결 프록시를 반영했다.
- 결과 필드에 `total_transaction_cost`, `average_transaction_cost_bps`를 추가했다.

### 3.8 실시간 운영 시뮬레이터

추가 파일:

- `src/atlas_investment/realtime/replay.py`

기능:

- `HistoricalEventReplay`
- 과거 candle을 quote event처럼 재생한다.
- adaptive child order PAPER simulation과 연결해 부분체결 경로를 재현한다.

### 3.9 리서치 팩토리

추가 파일:

기능:

- momentum, volatility, volume, quality, value feature를 생성한다.
- alpha score와 promotion note를 함께 만든다.

### 3.10 문서/감사 고도화

추가 파일:

- `src/atlas_investment/governance/audit_trail.py`

기능:

- `AuditTrailWriter`
- payload hash를 남기는 append-only JSONL 감사 기록을 생성한다.
- 전략 버전, 파라미터 변경, 검증 결과, 승격/폐기 결정과 연결할 수 있다.

### 3.11 ML/AI 전략

수정 파일:

- `src/atlas_investment/strategy/plugins.py`
- `src/atlas_investment/strategy/registry.py`
- `src/atlas_investment/portfolio/strategy_allocation.py`
- `src/atlas_investment/strategy/regime.py`
- `src/atlas_investment/cli.py`

기능:

- `MachineLearningAlphaStrategy`
- 전략명: `ml_alpha_score`
- alias: `ml`, `ai`, `machine_learning`
- feature: 20/60/120일 momentum, realized volatility, quality, value, earnings revision, trend, nonlinear interaction
- `quant-portfolio`와 `ensemble-backtest` 기본 전략군에 연결했다.
- bear regime에서는 ML alpha weight를 줄이고 bull regime에서는 높인다.

## 6. 남은 주의점

- `ml_alpha_score`는 실제 학습된 neural network나 boosting 모델이 아니라 deterministic ML-style feature ensemble이다.
- 실제 ML 모델 학습은 survivorship-bias-free universe, label 정의, train/validation/test split, feature store, model registry, drift monitoring, explainability가 필요하다.
- 현재 구현은 외부 데이터 없이 내부 소프트웨어 프레임워크를 완성하는 방향이다.
- 실거래 live 승격은 여전히 공식 API, 실시간 데이터, 계좌 대사, 운용 증거가 붙은 뒤에만 가능하다.

- 전략 자동 보정

- 현실적 비용/시장충격 반영 백테스트

- historical event replay
- factor research factory
- hash 기반 audit trail
- ML-style alpha 전략

외부 조건을 제외한 내부 고도화는 한 단계 더 완료됐다.
