# Atlas Investment 전체 검증 감사 보고서

> 최신 기준(2026-05-31): Atlas Investment은 토스증권 공식 API 출시 전 안전한 PAPER/DRY_RUN 운용 OS입니다. 완성된 글로벌 헤지펀드 또는 실거래 봇으로 판정하지 않습니다. 토스 플랫폼 범위는 KR/US 주식·ETF·채권·미국주식 옵션 중심이며, 직접 선물·현물 FX·직접 원자재 거래는 공식 지원 전까지 제외합니다. 실거래는 공식 API adapter 구현, read-only reconciliation, 30일 heartbeat, promotion evidence 통과 후에만 검토합니다.

작성일: 2026-05-30

이 문서는 Atlas Investment / 아틀라스 인베스트먼트의 현재 구현 상태를 네 가지 기준으로 점검한 결과입니다.

1. 토스증권 공식 API 부분을 제외한 Phase 8 구현 및 정상 동작 여부
2. 관련 문서 작성 상태
3. Atlas Investment 명칭 변경 상태
4. 완전 무인 자동화 가능 여부

## 1. Phase 8 구현 및 정상 동작 여부

검증 결과: 조건부 통과

토스증권 공식 API와 실제 시장 데이터 계약이 필요한 부분을 제외하면, 현재 로컬에서 검증 가능한 Phase 8 골격은 정상 동작합니다.

정상 동작을 확인한 기능은 다음과 같습니다.

- DRY_RUN 운용 사이클
- PAPER 운용 사이클
- OFF 모드 차단
- LIVE_AUTO 정책 차단
- 샘플 한국/미국 유니버스 생성
- 단일 종목 백테스트
- 여러 전략 비교와 랭킹 리포트 생성
- 일일 리스크 리포트 생성
- FX 오버레이 판단
- 실시간 이벤트 버스 스모크 테스트
- 운영 점검 리포트 생성
- 설치형 CLI `atlas-investment` 실행

현재 구현된 것은 실거래 운용사가 아니라, 실거래 API와 실제 데이터 공급원을 붙일 수 있는 기관급 운용 플랫폼 골격입니다.

## 4. 완전 무인 자동화 여부

검증 결과: 아직 아님

현재 프로그램은 무인 자동화를 목표로 하는 구조를 갖추고 있지만, 완전 무인 실거래 자동화 프로그램은 아닙니다.

현재 가능한 자동화는 다음과 같습니다.

- 유니버스 로드
- 신호 생성
- 투자위원회식 판단
- 주문 후보 생성
- 리스크 검증
- DRY_RUN 기록
- PAPER 가상 체결
- 백테스트
- 전략 비교
- 리스크 리포트
- 운영 리포트

아직 불가능하거나 의도적으로 막아 둔 부분은 다음과 같습니다.

- 토스증권 실계좌 조회
- 토스증권 실시간 시세 WebSocket 연결
- 토스증권 실주문 제출
- 주문 정정/취소
- 실시간 체결 이벤트 처리
- 실제 한국장/미국장 전체 종목 마스터 자동 갱신
- 실제 과거/실시간 OHLCV 데이터 공급원 연결
- 운영 서버 상시 실행
- 장애 감지 후 자동 복구
- 완전 무인 실거래 승인

`LIVE_AUTO`는 정책상 비활성화되어 있으며, 실행해도 차단됩니다. 이는 토스증권 공식 API 문서와 승인된 API 키가 공개되기 전까지 의도된 안전 동작입니다.

## 감사 중 수정한 사항

이번 감사 중 다음 문제를 발견하고 수정했습니다.

- `LIVE_AUTO`가 주문은 막으면서도 사이클 상태를 `ok`로 표시하던 문제를 `blocked`로 수정했습니다.
- `OFF` 모드가 주문은 막으면서도 사이클 상태를 `ok`로 표시하던 문제를 `blocked`로 수정했습니다.
- 두 동작을 검증하는 단위 테스트를 추가했습니다.
- 문서의 조사 오류를 수정했습니다.

## 남은 핵심 과제

완전 무인 실거래 자동화를 위해 아직 필요한 작업은 다음과 같습니다.

1. 토스증권 공식 REST/WebSocket API 문서 확보
2. 승인된 API 키와 계좌 권한 확보
3. `TossLiveBroker` 실제 구현
4. 실계좌 조회와 실시간 시세 연결
5. 실주문, 주문 정정, 주문 취소, 체결 이벤트 처리
6. 실제 한국/미국 전체 종목 마스터 연결
7. 실제 과거/실시간 데이터 공급원 연결
8. 운영 서버, 스케줄러, 헬스체크, 장애 복구
9. 실거래 전 소액/제한 모드 검증
10. 완전 무인 모드 승인 정책 확정

## 최종 판단

Atlas Investment은 현재 토스증권 공식 API 없이 가능한 Phase 8 운용 플랫폼 골격으로는 정상 동작합니다.

하지만 완벽한 무인 자동 실거래 시스템은 아직 아닙니다. 현재는 DRY_RUN/PAPER/백테스트/리포트/리스크/운영 점검까지 가능한 안전한 개발 단계이며, 실거래 자동화는 공식 토스증권 API가 공개된 뒤 별도 구현과 검증이 필요합니다.
