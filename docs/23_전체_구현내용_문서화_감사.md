# 전체 구현내용 문서화 감사

> 최신 기준(2026-05-31): Atlas Investment은 토스증권 공식 API 출시 전 안전한 PAPER/DRY_RUN 운용 OS입니다. 완성된 글로벌 헤지펀드 또는 실거래 봇으로 판정하지 않습니다. 토스 플랫폼 범위는 KR/US 주식·ETF·채권·미국주식 옵션 중심이며, 직접 선물·현물 FX·직접 원자재 거래는 공식 지원 전까지 제외합니다. 실거래는 공식 API adapter 구현, read-only reconciliation, 30일 heartbeat, promotion evidence 통과 후에만 검토합니다.

작성일: 2026-05-30

## 목적

지금까지 Atlas Investment에 구현한 기능이 문서로 충분히 남아 있는지 확인하고, 사용자가 나중에 코드와 문서를 함께 추적할 수 있도록 기능별 위치, 명령, 검증 상태, 남은 한계를 한 문서에 모은다.

## 결론

문서화 상태는 전반적으로 양호하다. Phase별 진행 기록, API 제외 보강 기록, ETF 비용 최적화 기록이 각각 남아 있다.

다만 다음 세 가지가 부족했다.

- 전체 구현 기능을 한눈에 보는 문서화 감사표
- 비용 체계의 현재 구현 범위와 미구현 범위에 대한 명확한 표
- ETF 비용 최적화가 기존 비용/리밸런싱 체계에서 어떤 역할을 하는지에 대한 연결 설명

이 문서가 그 부족분을 보강한다.

## 비용 체계 문서화

비용 체계는 일부 구현되어 있으며 완전한 펀드 비용 엔진은 아직 아니다.

| 비용 항목 | 현재 상태 | 구현/문서 위치 |
| --- | --- | --- |
| 백테스트 수수료 | 부분 구현 | `src/atlas_investment/backtest/engine.py` |
| 백테스트 슬리피지 | 부분 구현 | `src/atlas_investment/backtest/engine.py` |
| 일반 비용 모델 | 구현 | `src/atlas_investment/backtest/costs.py` |
| 거래세 | 모델 있음, 전체 엔진 미연결 | `src/atlas_investment/backtest/costs.py` |
| 환전 스프레드 | 모델 있음, 전체 엔진 미연결 | `src/atlas_investment/backtest/costs.py` |
| 운용보수 | 미구현 | 향후 `CostPolicy`/`FundFeeModel` 필요 |
| 성과보수 | 미구현 | 향후 high-water mark/hurdle rate 필요 |
| ETF 총보유비용 비교 | 구현 | `src/atlas_investment/portfolio/etf_optimizer.py`, `docs/22_ETF_비용최적화_엔진.md` |

비용 관련 다음 보강 권장 사항:

- `config/cost_policy.json` 추가
- 한국장/미국장/외환별 수수료, 세금, 환전비용 정책화
- 운용보수 일할 차감
- 성과보수 high-water mark와 hurdle rate 계산
- 백테스트, 포트폴리오, PAPER, 회계 원장에 동일 비용 정책 적용
- `cost-report` CLI 추가

## ETF 비용 최적화의 역할

ETF 비용 최적화는 일반 거래비용 모델과 별도로, 같은 익스포저를 가진 ETF 후보 중 어떤 상품을 살지 고르는 라우팅 계층이다.

예:

```text
필요 익스포저: NASDAQ100_KR_UNHEDGED
후보:
- KODEX 미국나스닥100TR
- TIGER 미국나스닥100
- ACE 미국나스닥100
```

비교 항목:

- 총보수
- 기타비용
- 추적오차
- 매매 수수료
- 매수/매도 스프레드
- 거래대금 부족 패널티
- 괴리율/프리미엄 패널티
- 기존 보유 ETF 교체비용
- 교체 안전마진

교체 기준:

```text
예상 절감액 > 교체 거래비용 + 안전마진
```

따라서 보수가 더 낮은 ETF가 있어도, 매도/매수 비용과 세금, 스프레드를 감안하면 유지가 더 유리할 수 있다.

## 여전히 명확히 남겨야 하는 한계

다음은 코드가 부족해서가 아니라 외부 API/데이터 연결 없이는 완성할 수 없는 영역이다.

- 실제 실시간 호가/체결
- 실제 주문 제출/정정/취소
- 실제 계좌 reconciliation
- 전체 시장의 완전한 생존편향 제거 데이터
- 외부 데이터 벤더 수준의 배당/분할/corporate action 보정
- ETF 최신 총보수, 기타비용, 실시간 괴리율, 실시간 호가 스프레드 자동 갱신

다음은 API 없이도 추가 구현할 수 있는 영역이다.

- 통합 `CostPolicy`/`FundFeeModel`
- 운용보수/성과보수 계산
- 비용 민감도 분석
- ETF 후보 DB 확장
- 리밸런싱 엔진과 ETF 비용 최적화의 자동 연결
- 비용 최적화 결과를 투자위원회 메모에 자동 반영
