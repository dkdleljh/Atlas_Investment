## 5. Tossctl 설치 시도와 결과

시도한 명령:

```bash
brew tap JungHoonGhae/tossinvest-cli
brew install tossctl
```

결과:

```text
Tapped 1 formula.
Error: junghoonghae/tossinvest-cli/tossctl: formula requires at least a URL
```

원인:

- tap 자체는 설치됐다.
- formula는 macOS용 `url`만 있고 Linux용 `url`이 없다.
- 현재 환경은 Linux이므로 Homebrew가 설치할 active spec을 찾지 못한다.

판정:

- `tossctl`은 현재 이 환경에서 설치 완료할 수 없다.
- 임의 HTTP 재구현이나 비공식 우회는 하지 않는 것이 맞다.
- `toss-securities` npm wrapper는 설치됐지만, 실제 계좌 조회는 upstream `tossctl` 바이너리와 로그인 세션이 있어야 한다.

## 8. 결론

현재 환경에서 설치 및 연결 가능한 항목은 모두 완료됐다.

완료:

- Python runtime/dependencies
- Atlas editable install
- `pygount`
- Node/npm
- `toss-securities` read-only wrapper
- 로컬 금융/점검 스킬
- GitHub/Hugging Face/Google Drive MCP 바인딩
- `mcp-catalog`와 `integration-check` 연결

남은 항목:

- `tossctl-readonly`: upstream Homebrew formula가 Linux용 URL을 제공하지 않아 설치 불가.

따라서 정확한 최종 상태는 다음과 같다.

> Atlas Investment 구동과 내부 검증에 필요한 의존성, MCP, 스킬은 전부 설치/연결됐다. 단, 토스증권 read-only 실계좌 조회용 `tossctl` 바이너리는 현재 Linux 환경에서 upstream formula 결함 때문에 설치할 수 없어 blocked 상태로 남는다.
