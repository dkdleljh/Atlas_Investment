> 최신 기준(2026-05-31): Atlas Investment은 토스증권 공식 API 출시 전 안전한 PAPER/DRY_RUN 운용 OS입니다. 완성된 글로벌 헤지펀드 또는 실거래 봇으로 판정하지 않습니다. 토스 플랫폼 범위는 KR/US 주식·ETF·채권·미국주식 옵션 중심이며, 직접 선물·현물 FX·직접 원자재 거래는 공식 지원 전까지 제외합니다. 실거래는 공식 API adapter 구현, read-only reconciliation, 30일 heartbeat, promotion evidence 통과 후에만 검토합니다.

작성일: 2026-05-30 17:50 KST

## 목적

토스증권 실API 연결 부분을 제외하고 Atlas Investment 프로그램 전체가 정상 작동하는지 다시 확인한다.

이번 검증은 단순 문서 확인이 아니라, 실제 Python 컴파일, 의존성 검사, 단위 테스트, 핵심 CLI 실행, 리포트 생성까지 포함한다.

## 결론

토스증권 실API 연결, DART API 키, tossctl read-only 계좌 조회처럼 외부 키/도구가 필요한 영역을 제외하면 프로그램은 정상 작동한다.

아래 항목은 모두 통과했다.

```text
Python compileall 통과
전체 unittest 43개 통과
pip check 통과
설치형 CLI atlas-investment --help 정상
DRY_RUN 운용 정상
PAPER 운용 정상
핵심 CLI smoke 26개 정상 종료
한국주식 검색/스냅샷 정상
미국 yfinance OHLCV 수집 정상
문서/리포트 생성 정상
```

다만 일부 명령은 `blocked` 또는 `degraded`를 반환했다. 이는 프로그램 오류가 아니라 안전 정책 또는 외부 연결 미비를 명확히 표시하는 정상 동작이다.

## `blocked`와 `degraded` 상세 판정

### `integration-check`: degraded

원인:

```text
tossctl-readonly: blocked
k-dart: blocked
```

상세:

- `requests`, `yfinance`, `pandas`, `numpy`, `node`, `npm`, `yfinance-data`는 정상이다.
- `tossctl`은 현재 Linux 환경에서 설치/로그인이 되어 있지 않아 read-only 계좌 조회만 차단된다.
- `API_K_DART` 환경변수가 없어 DART 실제 호출은 차단된다.

이는 토스증권 실API 연결 제외 조건과 외부 키 미설정 조건에 해당한다.

### `risk-report`: blocked

원인:

```text
VOO 단일 종목 비중이 한도를 초과했습니다.
```

판정:

정상이다. 리스크 리포트가 샘플 포트폴리오에서 단일 종목 비중 초과를 잡아냈다. 프로그램 실패가 아니라 리스크 차단 로직이 작동한 것이다.

### `governance-report`: blocked

원인:

```text
live_promotion: 토스 공식 주문 API와 수동 승인 절차 전까지 차단
```

판정:

정상이다. 실거래 전환 승인 항목만 차단되고, 전략 승인, 모델 변경 이력, 사고 포스트모템, 월간 리스크 리뷰, 킬스위치는 준비 상태다.

### `phase20-audit`: blocked

원인:

```text
dart_api_key: degraded
toss_readonly_cli: degraded
live_order_api: blocked
```

판정:

정상이다. API/키/외부 CLI가 없으면 라이브 운용 준비 완료로 표시하지 않도록 설계되어 있다.

### `strategy-validate`: degraded

원인:

```text
워크포워드 양수 수익 fold 비율이 낮습니다.
일부 검증 구간에서 거래가 발생하지 않았습니다.
```

판정:

정상이다. 실행 실패가 아니라 전략 검증 엔진이 성과/거래 부족 경고를 낸 것이다. 전략이 약하면 `degraded`로 표시해야 한다.

## 코드 검색 결과

`TODO`, `FIXME`, `NotImplemented`, `placeholder`, `sample`, `blocked`, `degraded` 키워드를 검색했다.

확인된 `NotImplementedError`는 다음 성격이다.

- `brokers/base.py`: 추상 브로커 인터페이스
- `data/vendors.py`: 추상 데이터 벤더 인터페이스
- `strategy/base.py`: 추상 전략 인터페이스

토스 실주문 브로커를 제외하면 실제 실행 CLI에서 터지는 미구현 지점은 발견되지 않았다.

`sample` 키워드는 주로 샘플 유니버스/샘플 ETF 비용 DB/문서 설명에서 확인됐다. 이는 실제 데이터 API 연결 전 개발용 데이터라는 한계로 남아 있다.
