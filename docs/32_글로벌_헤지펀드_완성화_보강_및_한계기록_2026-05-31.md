# 글로벌 헤지펀드 완성화 보강 및 한계 기록

> 최신 기준(2026-05-31): Atlas Investment은 토스증권 공식 API 출시 전 안전한 PAPER/DRY_RUN 운용 OS입니다. 완성된 글로벌 헤지펀드 또는 실거래 봇으로 판정하지 않습니다. 토스 플랫폼 범위는 KR/US 주식·ETF·채권·미국주식 옵션 중심이며, 직접 선물·현물 FX·직접 원자재 거래는 공식 지원 전까지 제외합니다. 실거래는 공식 API adapter 구현, read-only reconciliation, 30일 heartbeat, promotion evidence 통과 후에만 검토합니다.

작성일: 2026-05-31

## 요청

1. 남은 부족분을 전부 해결해서 완성된 글로벌 헤지펀드로 만들 것
2. 모든 과정과 결과를 문서로 남길 것

## 핵심 결론

이번 작업으로 코드만으로 해결 가능한 내부 결함은 추가 보강했다. 그러나 Atlas Investment을 **완성된 글로벌 헤지펀드**라고 판정할 수는 없다.

이유는 단순하다.

- 전체 글로벌 실거래 유니버스는 외부 공식/유료 데이터가 필요하다.
- 채권, 선물, 옵션, FX, 원자재는 자산별 계약/증거금/만기/롤오버/청산 규칙이 필요하다.
- 실계좌 reconciliation은 실제 broker read-only 스냅샷이 필요하다.
- 24x7 무인 운영 완성은 supervisor 설치 후 장기 heartbeat 이력이 필요하다.
- 전략 완성은 장기 out-of-sample/PAPER 실적과 퇴출/승격 기록이 필요하다.

따라서 코드만으로 임의 샘플을 만들어 readiness를 `ok`로 바꾸는 것은 부정확하다. Atlas Investment은 부족한 상태를 계속 `blocked`로 표시해야 한다.

## 이번에 실제로 해결한 항목

### 1. 기본 mock 포트폴리오 리스크 위반 제거

문제:

```text
risk-report: blocked
VOO 단일 종목 비중이 한도를 초과했습니다.
```

원인:

- 기본 `MockBroker` 포트폴리오의 VOO 비중이 정책상 단일 종목 한도를 넘었다.

수정:

```text
src/atlas_investment/brokers/mock.py
```

결과:

```json
{
  "status": "ok",
  "breaches": []
}
```

### 2. local-file 알림 엔진 추가

추가 파일:

```text
src/atlas_investment/ops/alerting.py
tests/test_ops_alerting.py
```

추가 명령:

```bash
.venv/bin/python -m atlas_investment.cli alerts-check
```

기능:

- `data/reports/*.json` 상태를 스캔한다.
- `blocked` 리포트는 critical alert로 기록한다.
- `degraded` 리포트는 warning alert로 기록한다.
- 외부 비밀 없이 `data/reports/alerts_outbox.jsonl`에 로컬 감사 흔적을 남긴다.

현재 결과:

```json
{
  "status": "blocked",
  "enabled": true,
  "channel_count": 1,
  "scanned_reports": 39,
  "event_count": 10,
  "outbox_path": "/home/zenith/Desktop/Atlas_Investment/data/reports/alerts_outbox.jsonl"
}
```

이 `blocked`는 알림 엔진 실패가 아니다. 실제로 blocked/degraded 리포트가 남아 있어 신규 실거래를 막아야 한다는 뜻이다.

### 3. systemd user service 템플릿 추가

추가 파일:

```text
deploy/atlas-investment.service
scripts/install_atlas_investment_user_service.sh
```

목적:

- `scripts/atlas_investment_daemon.sh`를 사용자 systemd 서비스로 등록할 수 있게 했다.
- `Restart=always`, `RestartSec=30`을 포함했다.

주의:

- 이번 작업에서는 서비스를 실제로 start하지 않았다.
- 실제 서비스 활성화와 30일 heartbeat 증빙 전까지 24x7 완전 무인 운영은 `degraded` 또는 `blocked`로 남아야 한다.
