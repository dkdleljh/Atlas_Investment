# Phase 7 토스 API 연결 준비 문서

> 최신 기준(2026-05-31): Atlas Investment은 토스증권 공식 API 출시 전 안전한 PAPER/DRY_RUN 운용 OS입니다. 완성된 글로벌 헤지펀드 또는 실거래 봇으로 판정하지 않습니다. 토스 플랫폼 범위는 KR/US 주식·ETF·채권·미국주식 옵션 중심이며, 직접 선물·현물 FX·직접 원자재 거래는 공식 지원 전까지 제외합니다. 실거래는 공식 API adapter 구현, read-only reconciliation, 30일 heartbeat, promotion evidence 통과 후에만 검토합니다.

## 현재 상태

토스증권 Open API는 아직 공식 문서가 공개되지 않은 상태입니다. 따라서 실주문 구현은 하지 않습니다.

## 이번 구현의 의미

토스 API가 공개되면 공식 문서를 반영한 adapter 구현을 바로 시작할 수 있도록 아래 계층을 분리해 두었습니다. 현재 `TossLiveBroker`는 placeholder이며, 공식 문서/키/계좌 식별자와 소액 검증 전에는 실주문을 보낼 수 없습니다.

- 브로커 계층: `brokers/`
- 실행 계층: `execution/`
- 실시간 이벤트 계층: `realtime/`
- 리스크 계층: `risk/`
- 감사 로그 계층: `journal/`

## 연결 후 구현할 순서

1. 공식 REST 인증
2. 계좌 조회
3. 현금 조회
4. 보유 종목 조회
5. 주문 가능 금액 조회
6. WebSocket 시세 연결
7. WebSocket 주문/체결 이벤트 연결
8. 주문 제출
9. 주문 취소/정정
10. 소액 실거래 검증

## 금지 사항

공식 API 없이 비공식 요청을 역공학해서 주문을 넣으면 안 됩니다. 계정 정지, 오주문, 법적/보안 문제가 생길 수 있습니다.
