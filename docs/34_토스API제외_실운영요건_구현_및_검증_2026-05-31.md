# 토스 API 제외 실운영 요건 구현 및 검증

> 최신 기준(2026-05-31): Atlas Investment은 토스증권 공식 API 출시 전 안전한 PAPER/DRY_RUN 운용 OS입니다. 완성된 글로벌 헤지펀드 또는 실거래 봇으로 판정하지 않습니다. 토스 플랫폼 범위는 KR/US 주식·ETF·채권·미국주식 옵션 중심이며, 직접 선물·현물 FX·직접 원자재 거래는 공식 지원 전까지 제외합니다. 실거래는 공식 API adapter 구현, read-only reconciliation, 30일 heartbeat, promotion evidence 통과 후에만 검토합니다.

작성일: 2026-05-31

## 요청

다음 항목 중 토스증권 공식 API가 아직 출시되지 않은 부분을 제외하고, 코드로 구현 가능한 감사/운영 체계를 최대한 완성한다. 실제 라이선스·실계좌·장기 운영 이력이 필요한 항목은 허위로 완료 처리하지 않는다.

- 전체 글로벌 tradable instrument master
- 실제 bond/future/option/fx/commodity 거래 가능 universe
- 라이선스 있는 survivorship-bias-free 데이터
- 실계좌 read-only reconciliation
- systemd 서비스 실제 운영 및 30일 heartbeat
- DRY_RUN/PAPER/소액 실주문/live promotion 증빙
- 토스 공식 API 문서/키/계좌 정보

## 처리 원칙

실제 라이선스, 실계좌, 30일 운영 이력, 소액 실주문 기록은 허위로 생성하지 않는다. 대신 해당 요건을 파일과 감사 명령으로 검증하도록 구현했다.

## 이번에 추가 구현한 항목

### 1. 라이선스 데이터 entitlement 감사

추가 파일:

```text
src/atlas_investment/data/entitlements.py
config/data_entitlements.json
```

추가 명령:

```bash
.venv/bin/python -m atlas_investment.cli data-entitlements
```

검증 항목:

- 실제 licensed provider 존재 여부
- KR/US/EU/JP/HK/CN/EM 시장 권리
- stock/etf/bond/future/option/fx/commodity 권리
- survivorship-bias-free 데이터 권리
- corporate action 조정 데이터 권리
- realtime market data 권리

현재 결과:

```json
{
  "status": "blocked",
  "provider_count": 0,
  "blocked": 6
}
```

판정:

- 정상적인 차단이다.
- sample/yfinance는 라이선스 있는 기관급 데이터 증거로 인정하지 않는다.

### 2. heartbeat 기록 및 30일 운영 감사

추가 파일:

```text
src/atlas_investment/ops/heartbeat.py
```

추가 명령:

```bash
.venv/bin/python -m atlas_investment.cli heartbeat-record --status ok --source manual-smoke
.venv/bin/python -m atlas_investment.cli heartbeat-audit
```

검증 항목:

- `data/runtime/heartbeat_history.jsonl` 기록
- distinct UTC day 수
- 최신 heartbeat 상태
- 30일 이상 운영 이력

현재 결과:

```json
{
  "status": "blocked",
  "distinct_utc_days": 1,
  "latest_status": "ok"
}
```

판정:

- 서비스는 시작됐지만 30일 운영 이력은 아직 없다.
- 따라서 24x7 완성 판정은 아직 불가하다.

## 아직 blocked인 이유

토스 공식 API를 제외해도 다음은 아직 실제 증거가 필요하다.

### 글로벌 tradable instrument master

현재:

```text
16 tradable assets across markets=['KR', 'US']
```

필요:

- 전체 KRX/US/EU/JP/HK/CN/EM 종목
- 상장폐지/거래정지/심볼 변경 이력

### 실제 다자산군 tradable universe

현재:

```text
covered=['etf', 'stock']
missing=['bond', 'commodity', 'future', 'fx', 'option']
```

필요:

- 실제 거래 가능한 bond/future/option/fx/commodity universe
- 자산군별 계약/증거금/만기/청산/롤오버 규칙

### 라이선스 데이터

현재:

```text
data_entitlements_status=blocked
provider_count=0
```

필요:

- 실제 계약된 provider
- 권리 범위와 데이터 품질 증빙

### 실계좌 read-only reconciliation

현재:

```text
tossctl=missing
reconciliation_status=blocked
```

토스 공식 API는 제외하더라도, 실계좌 read-only 스냅샷 자체는 실제 계좌/도구가 필요하다.

### 30일 heartbeat

현재:

```text
heartbeat_days=1
```

필요:

```text
heartbeat_days >= 30
latest_status == ok
```

### promotion evidence

현재:

```text
blocked_requirements=5
```

필요:

- DRY_RUN 30영업일
- PAPER 30영업일
- read-only reconciliation 10영업일
- 수동 소액 주문 검증
- live promotion approval

## 최종 판정

이번 작업으로 토스 API 제외 실운영 요건의 **감사 체계와 systemd 실제 운영 시작**까지 구현했다.

그러나 완성된 글로벌 헤지펀드 판정은 아직 차단이다. 차단 사유는 코드 부족이 아니라 실제 외부 증빙 부족이다.

정확한 상태:

> Atlas Investment은 토스 API 제외 기준에서도 완성 판정을 자동으로 검증할 수 있는 감사 체계를 갖췄고, systemd user service도 실제 active 상태다. 하지만 글로벌 데이터 라이선스, 실제 글로벌 instrument master, 다자산군 거래 universe, 실계좌 reconciliation, 30일 운영 이력, promotion evidence가 들어오기 전까지 완성된 글로벌 헤지펀드로 판정하지 않는다.
