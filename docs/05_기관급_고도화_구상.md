# Atlas Investment 기관급 고도화 구상

> 최신 기준(2026-05-31): Atlas Investment은 토스증권 공식 API 출시 전 안전한 PAPER/DRY_RUN 운용 OS입니다. 완성된 글로벌 헤지펀드 또는 실거래 봇으로 판정하지 않습니다. 토스 플랫폼 범위는 KR/US 주식·ETF·채권·미국주식 옵션 중심이며, 직접 선물·현물 FX·직접 원자재 거래는 공식 지원 전까지 제외합니다. 실거래는 공식 API adapter 구현, read-only reconciliation, 30일 heartbeat, promotion evidence 통과 후에만 검토합니다.

## 1. 목표

Atlas Investment의 최종 목표는 단순 자동매매 봇이 아니라, 여러 자산과 여러 전략을 동시에 운용하는 **글로벌 멀티에셋 운용 플랫폼**입니다.

대상 범위:

- 한국 주식
- 미국 주식
- 한국 ETF/ETN
- 미국 ETF
- 레버리지/인버스 상품
- 외환
- 현금/예수금

## 2. 핵심 방향

전략을 많이 넣는 것보다 먼저 운용 플랫폼의 골격이 튼튼해야 합니다.

기관급 구조는 아래 순서로 흘러야 합니다.

```text
유니버스
  -> 데이터 수집
  -> 기술지표/팩터 계산
  -> 전략 플러그인 신호 생성
  -> 백테스트 검증
  -> 포트폴리오 매니저 통합
  -> 리스크 엔진 검증
  -> 주문 실행
  -> 성과/위험/감사 리포트
```

## 3. 전략 계층

전략은 하나의 거대한 코드로 만들지 않고, 플러그인으로 분리합니다.

- 장기 투자 전략
- 스윙 전략
- 단타 전략
- 초단타 전략
- 스캘핑 전략
- 차트 기반 전략
- 이벤트 전략
- ETF 자산배분 전략
- 인버스 헤지 전략
- 외환 오버레이 전략

초단타와 스캘핑은 가장 나중에 붙입니다. 데이터 지연, 주문 지연, 호가 품질, API 제한에 매우 민감하기 때문입니다.

## 4. 리스크 원칙

주인님이 정한 정책은 최상위 정책입니다.

- 미수는 어떤 경우에도 금지
- 신용은 어떤 경우에도 금지
- 레버리지/인버스 종목은 허용
- 레버리지/인버스는 별도 총 비중 한도 필요
- 킬스위치가 켜지면 모든 신규 주문 중지

기관급으로 확장할 때 추가할 위험 지표:

- 일간 손실 한도
- 월간 손실 한도
- 최대 낙폭
- VaR
- CVaR
- 종목 집중도
- 섹터 집중도
- 시장별 비중
- 달러 노출
- 유동성 위험
- 주문 실패 위험
- API 장애 위험

## 5. 우선 개발 순서

지금부터의 우선순위는 아래가 맞습니다.

1. 전략 플러그인 구조
2. OHLCV 데이터 저장소
3. 백테스트 엔진
4. 기술지표 엔진
5. 한국/미국 전체 유니버스
6. 전략별 성과 비교
7. 포트폴리오 매니저 엔진
8. 기관급 리스크 엔진
9. 실시간 WebSocket 엔진
10. 토스증권 공식 API 연결

## 6. 현재 2차 버전에서 반영한 것

2차 버전에서는 기관급 플랫폼으로 가기 위한 최소 기반을 넣었습니다.

- 전략 플러그인 인터페이스
- 이동평균 교차 전략
- RSI 평균회귀 전략
- 신고가 돌파 전략
- OHLCV 저장소
- 샘플 OHLCV 생성기
- 단일 종목 백테스트 엔진
- 수수료/슬리피지 반영
- 손절/익절 반영
- 백테스트 성과 요약
- 백테스트 JSON 저장

이제 다음 단계는 실제 한국/미국 전체 유니버스와 실제 과거 데이터 공급원을 연결하는 것입니다.
