# 퀀트 전략 실거래 수준 확장 및 문서화

> 최신 기준(2026-05-31): Atlas Investment은 토스증권 공식 API 출시 전 안전한 PAPER/DRY_RUN 운용 OS입니다. 완성된 글로벌 헤지펀드 또는 실거래 봇으로 판정하지 않습니다. 토스 플랫폼 범위는 KR/US 주식·ETF·채권·미국주식 옵션 중심이며, 직접 선물·현물 FX·직접 원자재 거래는 공식 지원 전까지 제외합니다. 실거래는 공식 API adapter 구현, read-only reconciliation, 30일 heartbeat, promotion evidence 통과 후에만 검토합니다.

작성일: 2026-05-31

## 1. 요청

주인님은 퀀트 전략도 전부 실거래 수준으로 넣고, 모든 과정과 결과를 문서화하라고 요청했다.

이번 작업의 기준은 다음과 같다.

- 전략 아이디어만 적지 않고 실제 코드와 CLI로 실행 가능하게 만든다.
- 실거래에 가까운 포트폴리오 배분 레이어를 추가한다.
- 단, 공식 주문 API와 실시간 체결 인프라가 없는 상태에서 실주문 가능이라고 말하지 않는다.
- 모든 결과는 README와 이 문서에 남긴다.

## 2. 추가 구현

### 2.1 QVM 멀티팩터 전략

파일: `src/atlas_investment/strategy/plugins.py`

전략명: `multifactor_qvm`

Quality, Value, Momentum, Low Volatility, Yield를 하나의 점수로 결합한다.

- Quality: `quality_score`
- Value: `value_score`
- Momentum: 60일/120일 수익률
- Low Volatility: 60일 실현변동성
- Yield: 배당수익률

이 전략은 기존 단일 팩터보다 실전 운용에 더 적합한 복합 팩터 후보를 만들기 위한 것이다.

### 2.2 주주환원/Carry 전략

전략명: `shareholder_yield_carry`

주식형 carry를 현실적으로 구현했다.

- 배당수익률
- 자사주 매입 수익률
- 이익수익률
- payout quality

직접 FX carry나 원자재 carry는 토스 공식 지원 전까지 제외하고, 현재 토스 범위에서 가능한 주식/ETF형 carry로 제한한다.

### 2.3 섹터/스타일 로테이션 전략

전략명: `sector_regime_rotation`

시장 국면을 단순하지만 명시적으로 판단한다.

- 리스크온: 추세 양호, 변동성 안정
- 리스크오프: 추세 약화 또는 변동성 상승

리스크온에서는 성장/기술/시장대표 스타일을 선호하고, 리스크오프에서는 채권/헤지/방어적 broad market 노출을 선호한다.

### 2.4 실적 이벤트 퀀트 전략

전략명: `earnings_revision_event`

실적 추정치 변화, 실적 서프라이즈, 거래량 반응을 결합한다.

현재는 메타데이터와 거래량 프록시 기반이다. 향후 DART, SEC filings, earnings calendar, consensus data가 연결되면 실제 이벤트 데이터로 교체할 수 있다.

### 2.6 CLI 추가

명령:

```bash
.venv/bin/python -m atlas_investment.cli quant-portfolio --max-symbols 8 --days 220
.venv/bin/python -m atlas_investment.cli strategy-allocation --max-symbols 8 --days 220
```

동작:

1. 샘플/데이터레이크 OHLCV를 로드한다.
2. QVM, 추세, 모멘텀, 저변동성, carry, 로테이션, 이벤트 전략을 실행한다.
3. 신호를 앙상블한다.
4. 종목/섹터 한도를 적용한다.
5. 결과를 `data/reports/quant_portfolio.json`에 저장한다.

## 4. 실거래 수준에 가까워진 점

- 단일 전략이 아니라 복수 전략을 포트폴리오 후보로 합치는 앙상블 레이어가 생겼다.
- 팩터 전략이 단순 quality/momentum에서 QVM/Low Vol/Yield 조합으로 확장됐다.
- 섹터 쏠림 한도를 코드로 적용한다.
- 단일 종목 목표비중을 제한한다.
- 모든 결과가 JSON 리포트로 남는다.
- 전략은 늘렸지만 LIVE_AUTO 주문은 공식 외부 요건 없이는 여전히 차단한다.

## 5. 아직 완벽한 실거래라고 말하면 안 되는 이유

아래는 코드만으로 해결할 수 없는 외부 요건이다.

- 토스 공식 주문 API 문서와 실제 주문 권한
- 실시간 호가/체결 스트림
- 미체결 정정/취소
- 실계좌 position/cash/fill reconciliation
- 실제 재무 팩터 데이터 라이선스
- survivorship-bias-free 글로벌 유니버스
- 실적 추정치/컨센서스 데이터
- 30일 이상 DRY_RUN/PAPER heartbeat와 promotion evidence

따라서 이번 구현은 **실거래 승격 가능한 퀀트 엔진 강화**이지, 아직 **실주문 가능한 완성 봇**은 아니다.

## 6. 검증

검증 명령:

```bash
.venv/bin/python -m compileall -q src tests
.venv/bin/python -m unittest discover -s tests -q
.venv/bin/python -m atlas_investment.cli quant-portfolio --max-symbols 8 --days 220
.venv/bin/python -m atlas_investment.cli strategy-lab --max-symbols 4 --days 220 --strategies multifactor_qvm,shareholder_yield_carry,sector_regime_rotation,earnings_revision_event
.venv/bin/python -m pip check
systemctl --user restart atlas-investment.service
systemctl --user is-active atlas-investment.service
```

