# 50. 전체 코드 점검 및 MCP/스킬 연결 감사

검증일: 2026-06-01 KST

## 1. 요청

사용자는 Atlas Investment 코드를 전체적으로 점검하고, 연관된 MCP나 스킬이 있으면 찾아서 전부 연결하라고 요청했다.

## 2. 사용한 스킬과 MCP

사용한 로컬 스킬:

- `repo-doctor`: git 상태, dirty 파일, 테스트 힌트 점검
- `workspace-map`: 워크스페이스 프로젝트 위치 확인
- `hermes-github-codebase-inspection`: 코드베이스 구성 점검용. 단, `pygount`가 설치되어 있지 않아 `rg/wc` 기반 LOC로 대체했다.
- `korean-stock-search`: KRX 종목 검색/일별 시세 proxy 연결 지침 확인
- `k-dart`: OpenDART 공시/재무 API 연결 지침 확인
- `toss-securities`: 토스증권 read-only `tossctl` 연결 지침 확인

사용한 MCP:

- GitHub MCP: 설치된 GitHub 저장소 검색. Atlas Investment 원격 저장소는 현재 GitHub App 설치 목록에서 발견되지 않았다.
- Hugging Face MCP: ML/AI 퀀트 논문 검색. ML asset pricing, transformer, reinforcement-learning allocation 관련 논문 후보를 확인했다.

## 7. 남은 조치

외부 도구 설치가 필요한 항목:

- `pygount`: 정밀 언어별 LOC 리포트가 필요하면 설치한다.
- `tossctl`: 토스증권 read-only 계좌/포지션/체결 스냅샷을 실제로 쓰려면 설치와 로그인이 필요하다.
- GitHub remote: Atlas Investment을 원격 저장소와 연결하려면 remote를 추가하고 GitHub App 설치 대상에 포함해야 한다.

코드상 즉시 수정할 치명적 결함:

- 이번 점검 범위에서는 발견하지 못했다.

## 8. 결론

전체 코드 점검 결과, 현재 테스트와 내부 감사 기준으로 즉시 깨지는 부분은 없다.

연관된 로컬 스킬과 MCP는 `mcp-catalog`와 `integration-check` 경로에 연결했다. 단, `tossctl`과 GitHub remote처럼 실제 외부 설치/계정 상태가 필요한 항목은 연결 지점만 준비되어 있고 실행 상태는 외부 조건에 따른다.
