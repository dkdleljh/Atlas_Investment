# 글로벌 헤지펀드 수준 재검증

> 최신 기준(2026-05-31): Atlas Investment은 토스증권 공식 API 출시 전 안전한 PAPER/DRY_RUN 운용 OS입니다. 완성된 글로벌 헤지펀드 또는 실거래 봇으로 판정하지 않습니다. 토스 플랫폼 범위는 KR/US 주식·ETF·채권·미국주식 옵션 중심이며, 직접 선물·현물 FX·직접 원자재 거래는 공식 지원 전까지 제외합니다. 실거래는 공식 API adapter 구현, read-only reconciliation, 30일 heartbeat, promotion evidence 통과 후에만 검토합니다.

작성일: 2026-05-31

## 질문

토스증권 API가 공식 출시되면 Atlas Investment을 바로 연결해 가동할 계획이다. 현재 프로그램이 확실하게 글로벌 헤지펀드 수준인지 검증한다.

## 결론

현재 Atlas Investment은 **글로벌 헤지펀드 수준의 운용 OS 골격과 안전 게이트를 갖춘 연구/준비 시스템**이다. 그러나 **토스증권 API만 붙이면 곧바로 글로벌 헤지펀드 수준이 되는 상태는 아니다.**

현재 판정:

- 글로벌 초거대 헤지펀드 수준: `blocked`
- 365일 24x7 무인 실거래 자동화: `blocked`
- 공식 토스증권 API 실거래 준비: `blocked`
- 내부 리스크 통제 골격: `ok`
- 문서/감사 산출물: `ok`

## 왜 아직 글로벌 헤지펀드 수준이 아닌가

### 1. 글로벌 유니버스 부족

현재 감사 결과:

```text
16 tradable assets across markets=['KR', 'US']
```

글로벌 헤지펀드 수준이라면 최소한 다음이 필요하다.

- KRX 전체 종목과 ETF
- 미국 전체 상장주식/ETF
- 유럽, 일본, 홍콩, 중국, 신흥국
- 상장폐지, 거래정지, 관리종목, 심볼 변경 이력
- survivorship bias가 제거된 종목 마스터

현재는 샘플/개발용 유니버스에 가깝다.

### 2. 자산군 부족

현재 커버:

```text
stock, etf
```

부족:

```text
bond, commodity, future, fx, option
```

토스증권 API가 국내외 주식 매매 자동화를 제공하더라도, 그것만으로 채권, 선물, 옵션, FX, 원자재까지 운용하는 글로벌 멀티애셋 헤지펀드가 되지는 않는다.

### 3. 데이터 품질 부족

현재 감사 결과:

```text
ohlcv_csv_count=4
```

글로벌 운용에는 다음이 필요하다.

- 공식/유료 시세 데이터
- 배당, 액면분할, 권리락, 상장폐지 조정
- 실시간 호가/체결 데이터
- 데이터 지연/누락 감지
- 공급원 장애 시 failover
- 백테스트용 survivorship-bias-free 데이터셋

현재 데이터 계층은 연구/개발용으로는 유효하지만 기관 실거래 수준은 아니다.

### 4. 토스증권 공식 API 미확정

현재 `readiness` 결과:

```json
{
  "status": "blocked",
  "ready_for_live_orders": false,
  "official_docs_verified": false,
  "missing_items": [
    "공식 API 문서 URL",
    "공식 REST API base URL",
    "공식 WebSocket URL",
    "공식 app key",
    "공식 app secret",
    "공식 계좌 식별자"
  ]
}
```

공식 API가 출시되면 필요한 작업:

1. 공식 문서 URL 검증
2. REST/WebSocket base URL 등록
3. 인증/토큰 갱신 구현
4. 주문, 정정, 취소 구현
5. 체결 이벤트 구현
6. 계좌/잔고/포지션 조회 구현
7. rate limit, 장애, idempotency 처리
8. 소액 주문으로 실제 reconciliation 검증

### 5. read-only reconciliation 미완료

현재 결과:

```json
{
  "status": "blocked",
  "broker_position_count": 0,
  "difference_count": 2
}
```

차단 이유:

- `data/toss_readonly/positions.json` 없음
- 내부 활성 주문/보유 종목이 broker 스냅샷과 대조되지 않음

실거래 승격 전에는 최소 10거래일 이상 read-only 계좌/포지션/주문/체결 대조가 무차이로 통과해야 한다.

### 6. 24x7 운영은 템플릿 단계

현재 상태:

- daemon script 있음
- automation policy 있음
- dashboard 있음

부족:

- systemd/supervisor 등록 없음
- restart policy 검증 없음
- 30일 heartbeat 기록 없음
- Telegram/email/Slack 알림 채널 없음
- 알림 실패 재시도 없음

## 현재 좋은 점

다음은 기관형 운용 OS의 방향과 맞다.

- 미수/신용 하드 차단
- 단일 주문 리스크 검사
- batch 주문 리스크 검사
- PAPER/DRY_RUN 경로
- 토스 공식 API 없으면 live 차단
- 비공식/역공학 API 실거래 금지
- read-only reconciliation 게이트
- 백테스트 다음 봉 체결
- 문서화와 readiness 감사 CLI

## 최종 판정

토스증권 공식 API가 출시되면 Atlas Investment은 **바로 연결 작업을 시작할 수 있는 준비된 코드베이스**다. 그러나 연결 즉시 “글로벌 헤지펀드 수준”으로 판정하면 안 된다.

정확한 승격 단계는 다음이다.

1. 공식 API 문서와 credentials 확보
2. Toss live broker adapter 구현
3. read-only reconciliation 10거래일 통과
4. DRY_RUN/PAPER 30영업일 무장애 통과
5. 소액 수동 승인 실주문 검증
6. 알림/daemon supervisor 운영 증빙
7. 글로벌 유니버스와 기관급 데이터 확장
8. live promotion approval 문서화

이 단계 전까지 Atlas Investment의 올바른 명칭은 **글로벌 헤지펀드급 운용 OS 골격 / 실거래 승격 준비 시스템**이다.
