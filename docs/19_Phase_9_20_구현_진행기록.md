# Phase 9-20 구현 진행 기록

> 최신 기준(2026-05-31): Atlas Investment은 토스증권 공식 API 출시 전 안전한 PAPER/DRY_RUN 운용 OS입니다. 완성된 글로벌 헤지펀드 또는 실거래 봇으로 판정하지 않습니다. 토스 플랫폼 범위는 KR/US 주식·ETF·채권·미국주식 옵션 중심이며, 직접 선물·현물 FX·직접 원자재 거래는 공식 지원 전까지 제외합니다. 실거래는 공식 API adapter 구현, read-only reconciliation, 30일 heartbeat, promotion evidence 통과 후에만 검토합니다.

작성일: 2026-05-30

## 목표

Atlas Investment을 한국장, 미국장, 외환, 스캘핑, 단타, 스윙, 장기투자, 리밸런싱, 퀀트 전략을 모두 수용할 수 있는 헤지펀드 OS 구조로 확장한다.

실거래 주문은 토스증권 공식 주문 API가 준비되기 전까지 계속 차단한다. 이번 구현은 데이터, 연구, 리스크, 운영, 거버넌스 계층을 실제 CLI로 사용할 수 있게 만드는 단계다.

## 구현 범위

### Phase 9: 실제 데이터 레이크 골격

- `data-sync` 명령 추가
- 종목 마스터를 `data/lake/instrument_master.json`에 저장
- 한국/미국 샘플 유니버스 OHLCV를 `data/lake/ohlcv/`에 저장
- USD/KRW 샘플 환율 데이터를 `data/lake/fx/USD_KRW.csv`에 저장
- OHLCV 품질 점검 결과를 함께 기록

### Phase 10: 전략 연구소

- `strategy-lab` 명령 추가
- 여러 전략과 여러 종목의 백테스트 결과를 한 번에 랭킹화
- 안정성 점수, PAPER 승격 가능 여부, 전략별 주석 생성
- 전략 플러그인 확장:
  - `long_term_trend`
  - `volatility_breakout`
  - `swing_momentum`
  - `scalping_simulation`
  - `etf_rebalance`
  - `factor_quality`
  - `fx_overlay_signal`
  - `event_disclosure_watch`

### Phase 11: 초단기/스캘핑 엔진

- `scalping_simulation` 전략 추가
- 공식 실시간 호가/체결 API 전까지 스캘핑은 시뮬레이션 후보만 생성
- 실주문 라우팅은 계속 차단

### Phase 12-13: 포트폴리오/리스크 총괄

- `fund-risk` 명령 추가
- 펀드 단위 총 익스포저, 현금 버퍼, 레버리지/인버스 한도 사용률 계산
- 손실 한도 기반 자동 감속/차단 액션 생성

### Phase 14: 백테스트 신뢰도 고도화 기반

- 전략 연구소가 기존 거래비용 반영 백테스트 엔진을 통합 사용
- 전략별 거래 횟수, 승률, 최대낙폭, 안정성 점수를 함께 기록

### Phase 15: 실행/브로커 계층

- `execution-sim` 명령 추가
- DRY_RUN/PAPER/LIVE_AUTO별 주문 라우팅 시뮬레이션
- LIVE_AUTO는 공식 API 준비 전까지 `blocked`로 표시
- 미수/신용 주문은 라우터에서도 즉시 차단

### Phase 16: 외환/멀티통화 엔진

- `fx-exposure` 명령 추가
- KRW/USD 자산 노출을 원화 기준으로 합산
- USD 노출 상태에 따른 리밸런싱/환율 필터 주석 생성

### Phase 17-18: 운영 자동화/대시보드

- 기존 cron, healthcheck, ops-report와 함께 사용 가능한 Phase 20 감사 명령 추가
- 보고서 파일은 `data/reports/`에 저장

### Phase 19: 투자위원회/리서치 자동화

- `investment-memo` 명령 추가
- PM, Quant, Risk, Execution, Compliance 관점의 투자 메모 생성
- 데이터 품질, 전략 연구, 펀드 리스크, 실행 라우트, 거버넌스 체크를 필수 확인 항목으로 기록

### Phase 20: 펀드급 거버넌스

- `governance-report` 명령 추가
- 전략 승인, 라이브 전환, 모델 변경, 사고 포스트모템, 월간 리스크 리뷰, 킬스위치 통제 항목 생성
- `phase20-audit` 명령 추가
- DART API 키, tossctl, 공식 실주문 API, 데이터 레이크, 문서 상태를 종합 점검

## 새 CLI 명령

```bash
.venv/bin/python -m atlas_investment.cli data-sync --max-symbols 4 --days 80
.venv/bin/python -m atlas_investment.cli strategy-lab --max-symbols 3 --days 120
.venv/bin/python -m atlas_investment.cli fund-risk
.venv/bin/python -m atlas_investment.cli fx-exposure
.venv/bin/python -m atlas_investment.cli execution-sim --mode live_auto --symbol 005930
.venv/bin/python -m atlas_investment.cli governance-report
.venv/bin/python -m atlas_investment.cli investment-memo --symbol 005930 --strategy moving_average_cross
.venv/bin/python -m atlas_investment.cli phase20-audit
```

## 남은 외부 의존성

- `API_K_DART`: 실제 DART 공시 조회용
- `tossctl`: 토스 read-only 계좌 스냅샷용
- 토스증권 공식 주문 API 문서/키: 실제 주문 라우팅용
- 실시간 호가/체결 데이터: 스캘핑과 초단타의 실전 검증용
