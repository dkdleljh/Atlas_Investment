# Atlas Investment 리스크 정책

> 최신 기준(2026-05-31): Atlas Investment은 토스증권 공식 API 출시 전 안전한 PAPER/DRY_RUN 운용 OS입니다. 완성된 글로벌 헤지펀드 또는 실거래 봇으로 판정하지 않습니다. 토스 플랫폼 범위는 KR/US 주식·ETF·채권·미국주식 옵션 중심이며, 직접 선물·현물 FX·직접 원자재 거래는 공식 지원 전까지 제외합니다. 실거래는 공식 API adapter 구현, read-only reconciliation, 30일 heartbeat, promotion evidence 통과 후에만 검토합니다.

## 1. 절대 금지

다음은 어떤 상황에서도 허용하지 않습니다.

- 미수 거래
- 신용 거래
- 현금 잔고를 초과하는 주문
- 킬스위치가 켜진 상태의 주문
- 토스증권 공식 API가 아닌 방식의 실주문

## 2. 허용

다음은 허용합니다.

- 일반 주식
- ETF
- ETN
- 레버리지 상품
- 인버스 상품
- 레버리지 인버스 상품

다만 레버리지/인버스 상품은 변동성이 높으므로 일반 종목보다 낮은 비중 제한을 적용합니다.

## 3. 현재 기본 한도

`config/risk_policy.json` 기준 기본값입니다.

- 최소 현금 비중: 15%
- 단일 일반 종목 최대 비중: 12%
- 레버리지/인버스 종목 최대 비중: 8%
- 하루 주문 금액 한도: 1,000,000원
- 하루 손실 한도: 300,000원
- 최대 보유 종목 수: 20개

## 4. 코드상 강제 방식

`RiskEngine`은 주문이 나가기 전에 다음을 확인합니다.

1. 킬스위치 확인
2. 실행 모드 확인
3. LIVE_AUTO 허용 여부 확인
4. 미수 사용 여부 확인
5. 신용 사용 여부 확인
6. 레버리지/인버스 허용 여부 확인
7. 주문 금액 한도 확인
8. 현금 잔고 확인
9. 최소 현금 비중 확인
10. 종목 비중 한도 확인
11. 최대 보유 종목 수 확인

하나라도 실패하면 주문은 실행되지 않습니다.
