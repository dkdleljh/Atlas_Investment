# 실거래봇 승격 준비 최종 보강 기록

> 최신 기준(2026-05-31): Atlas Investment은 토스증권 공식 API 출시 전 안전한 PAPER/DRY_RUN 운용 OS입니다. 완성된 글로벌 헤지펀드 또는 실거래 봇으로 판정하지 않습니다. 토스 플랫폼 범위는 KR/US 주식·ETF·채권·미국주식 옵션 중심이며, 직접 선물·현물 FX·직접 원자재 거래는 공식 지원 전까지 제외합니다. 실거래는 공식 API adapter 구현, read-only reconciliation, 30일 heartbeat, promotion evidence 통과 후에만 검토합니다.

작성일: 2026-05-31

## 결론

Atlas Investment은 아직 돈을 바로 맡겨 굴리는 실거래 봇이 아니다. 이번 보강의 목적은 실거래처럼 보이게 만드는 것이 아니라, 토스증권 공식 주문 API가 확인되기 전까지 실거래가 절대 열리지 않도록 막고, 공식 API 출시 시 공식 문서 기반 adapter 구현을 즉시 시작할 수 있는 기관형 운용 OS의 필수 부품을 실제 코드 경로에 붙이는 것이다.

현재 최종 판정:

- 글로벌 초거대 헤지펀드 여부: `blocked`
- 365일 24x7 완전 무인 자동화 여부: `blocked`
- 토스증권 공식 API 문서 준수 여부: `blocked`
- 실거래 주문 가능 여부: `blocked`
- PAPER/DRY_RUN 연구 운용 OS 여부: `ok`

## 토스증권 공식 API 문서 검증

2026-05-31 현재 확인 범위에서 토스증권의 공식 공개 주문 API 문서를 확인하지 못했다.

검색한 범위:

- 토스증권 Open API 공식 문서
- `site:tossinvest.com` 토스증권 API
- 토스증권 자동매매 REST/WebSocket API
- 토스증권 Open API 사전신청 및 출시 예정 관련 검색어

따라서 Atlas Investment은 다음을 요구하도록 바뀌었다.

- `TOSS_API_DOCS_URL`: 토스 공식 도메인의 HTTPS 문서 URL
- `TOSS_API_REST_BASE_URL`: 공식 REST base URL
- `TOSS_API_WEBSOCKET_URL`: 공식 WebSocket URL
- `TOSS_API_APP_KEY`
- `TOSS_API_APP_SECRET`
- `TOSS_API_ACCOUNT_ID`

검증 명령:

```bash
.venv/bin/python -m atlas_investment.cli readiness
```

현재 결과:

```json
{
  "status": "blocked",
  "ready_for_live_orders": false,
  "official_docs_verified": false
}
```

비공식 API, 역공학 API, 브라우저 자동화 주문, 화면 스크래핑 주문은 실거래 경로로 인정하지 않는다.

## 주문 batch 리스크 엔진

추가 파일:

```text
src/atlas_investment/risk/batch.py
```

보강 내용:

- 단일 주문 검사 후 전체 주문 묶음을 다시 시뮬레이션한다.
- 전체 매수금액이 일일 주문 한도를 넘으면 batch 전체를 차단한다.
- 주문 후 현금 잔고와 최소 현금 비중을 계산한다.
- 주문 후 보유 종목 수를 계산한다.
- 레버리지/인버스 상품의 합산 예상 비중을 계산한다.
- batch가 실패하면 이미 `validated` 상태인 주문도 `blocked`로 전환한다.

## 백테스트 look-ahead bias 제거

수정 파일:

```text
src/atlas_investment/backtest/engine.py
```

기존 문제:

- 신호를 생성한 같은 캔들의 종가로 즉시 체결했다.
- 그 캔들의 종가를 알고 신호를 낸 뒤 같은 종가로 체결하는 구조라 look-ahead bias가 있었다.

보강 내용:

- 기본 체결 지연을 `execution_lag_bars=1`로 설정했다.
- 신호는 현재 index까지의 데이터로 생성한다.
- 매수/매도 체결은 다음 봉 시가 기준으로 수행한다.
- 마지막 봉에서 새 신호가 나와도 다음 봉이 없으면 신규 체결하지 않는다.

고정 테스트:

- `tests/test_backtest.py`
- 첫 번째 봉에서 매수 신호가 나면 실제 매수 거래일은 두 번째 봉이어야 한다.

## 실계좌 read-only reconciliation

추가 파일:

```text
src/atlas_investment/ops/reconciliation.py
```

추가 명령:

```bash
.venv/bin/python -m atlas_investment.cli reconciliation-check
```

보강 내용:

- 내부 주문 상태 파일과 토스 read-only 포지션 스냅샷을 비교한다.
- read-only 스냅샷이 없으면 실거래 승격을 차단한다.
- 내부 활성 주문/보유 종목이 broker 스냅샷에 없으면 차단한다.
- broker 포지션이 내부 상태와 연결되지 않으면 degraded 또는 blocked로 보고한다.

  "internal_order_count": 72,
  "broker_position_count": 0,
  "difference_count": 2
}

차단 이유:

- `data/toss_readonly/positions.json`이 없다.
- 실계좌 read-only 동기화가 완료되지 않았다.

## 실거래 승격 조건

토스증권 공식 API가 출시되면 다음 순서로만 승격한다.

1. 공식 문서 URL과 base URL을 `TOSS_API_*` 환경변수에 등록한다.
2. 문서의 인증, rate limit, 주문, 정정, 취소, 체결 이벤트 스펙을 코드에 반영한다.
3. read-only 계좌/포지션/주문/체결 동기화를 10거래일 이상 무차이로 통과한다.
4. DRY_RUN과 PAPER를 30영업일 이상 무중단으로 통과한다.
5. 수동 승인 소액 주문으로 주문/정정/취소/체결 reconciliation을 검증한다.
6. 별도 문서의 live promotion approval 기록이 있어야 `allow_live_trading=true`를 고려한다.

이 조건 전에는 Atlas Investment이 돈을 직접 맡아 자동 운용한다고 표현하면 안 된다.
