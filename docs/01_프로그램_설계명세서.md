# Atlas Investment 프로그램 설계명세서

> 최신 기준(2026-05-31): Atlas Investment은 토스증권 공식 API 출시 전 안전한 PAPER/DRY_RUN 운용 OS입니다. 완성된 글로벌 헤지펀드 또는 실거래 봇으로 판정하지 않습니다. 토스 플랫폼 범위는 KR/US 주식·ETF·채권·미국주식 옵션 중심이며, 직접 선물·현물 FX·직접 원자재 거래는 공식 지원 전까지 제외합니다. 실거래는 공식 API adapter 구현, read-only reconciliation, 30일 heartbeat, promotion evidence 통과 후에만 검토합니다.

## 1. 프로젝트 개요

**Atlas Investment / 아틀라스 인베스트먼트**은 한국장과 미국장 전체를 대상으로 투자 대상 선정, 매매 판단, 매수/매도, 보유 기간 관리까지 자동화하는 주식 운용 프로그램입니다.

토스증권 Open API가 아직 사전 신청 단계이므로, 현재 버전은 공식 API 문서가 없어도 개발과 검증을 진행할 수 있는 **PAPER/DRY_RUN/백테스트 기반 2차 엔진**입니다. 실거래 연결은 토스증권의 공식 REST API와 WebSocket 문서가 공개된 뒤 `TossLiveBroker`에 구현합니다.

## 2. 핵심 목표

- 한국장과 미국장 전체 종목을 투자 후보로 다룰 수 있는 구조
- 여러 전략을 플러그인처럼 추가할 수 있는 구조
- 과거 OHLCV 데이터로 전략을 검증하는 백테스트 구조
- 차트 기반 전략을 위한 기술지표 구조
- 투자위원회 방식의 다중 관점 판단
- 주문 전 리스크 검사를 반드시 통과하는 구조
- 미수와 신용을 어떤 경우에도 차단
- 레버리지/인버스 종목은 허용하되 별도 비중 제한 가능
- 모든 판단과 주문 후보를 감사 로그로 남김
- 토스증권 API 공개 후 REST/WebSocket 어댑터를 쉽게 연결

## 3. 시스템 구조

```text
종목 유니버스
  -> 시세/OHLCV 데이터 조회
  -> 기술지표 계산
  -> 전략 플러그인 신호 생성
  -> 백테스트 또는 실시간 운용 경로 선택
  -> 투자위원회 판단
  -> 주문 후보 생성
  -> 리스크 엔진 검증
  -> 브로커 실행
  -> 감사 로그 저장
```

## 4. 주요 모듈

### 4.1 `market_data`

시세, 호가, 거래량, 과거 데이터 등을 다루는 영역입니다. 현재는 `MockBroker`가 샘플 시세를 제공합니다. 토스증권 API가 공개되면 REST/WebSocket 기반 실시간 데이터 수집기를 연결합니다.

### 4.2 `data`

투자 가능한 종목 유니버스와 OHLCV 데이터를 관리합니다. 현재는 샘플 한국/미국 종목과 결정론적 샘플 OHLCV 데이터를 제공합니다.

현재 구현:

- `sample_universe.py`: 한국/미국 샘플 종목
- `ohlcv_store.py`: CSV 기반 OHLCV 저장소
- `generate_sample_ohlcv`: 백테스트 검증용 샘플 가격 데이터 생성

향후 확장:

- KOSPI 전체
- KOSDAQ 전체
- 한국 ETF/ETN
- NYSE/NASDAQ/AMEX 전체
- 미국 ETF
- 거래정지/관리종목/저유동성 종목 제외

### 4.3 `strategy`

매수/매도 후보를 만드는 전략 영역입니다. 2차 버전부터 전략 플러그인 구조를 제공합니다.

현재 구현:

- `StrategyPlugin`: 모든 전략이 따라야 하는 공통 인터페이스
- `MovingAverageCrossStrategy`: 20일/60일 이동평균 기반 중기 추세 전략
- `RsiMeanReversionStrategy`: RSI 과매도/과열 기반 단기 평균회귀 전략
- `BreakoutMomentumStrategy`: 60일 신고가 돌파 기반 스윙 모멘텀 전략
- `StrategyRegistry`: 전략 이름으로 플러그인을 불러오는 등록소

향후 전략 예시:

- 스캘핑 전략
- 초단타 호가/체결 전략
- 장중 VWAP 전략
- 모멘텀 전략
- 퀄리티 전략
- 가치 전략
- 실적 이벤트 전략
- ETF 자산배분 전략
- 레버리지/인버스 헤지 전략
- 평균회귀 전략

### 4.4 `technical`

차트 기반 전략에 필요한 기술지표를 계산합니다.

현재 구현:

- 단순 이동평균 `SMA`
- 지수 이동평균 `EMA`
- RSI
- 최대 낙폭 계산

향후 확장:

- MACD
- Bollinger Bands
- ATR
- VWAP
- 거래량 지표
- 지지/저항
- 갭 상승/갭 하락
- 추세 강도

### 4.5 `backtest`

전략을 과거 데이터로 검증합니다. 현재는 단일 종목 단순 현금 계좌 방식의 백테스트를 제공합니다.

현재 반영:

- 초기 현금
- 매수/매도 신호
- 수수료
- 슬리피지
- 손절/익절
- 최종 평가금액
- 총수익률
- 최대 낙폭
- 거래 횟수
- 승률

### 4.6 `analytics`

백테스트 결과를 사람이 읽을 수 있는 요약과 JSON 파일로 저장합니다.

### 4.7 `committee`

투자위원회 판단을 담당합니다. 하나의 전략 신호를 바로 주문으로 바꾸지 않고, 여러 역할의 관점으로 검토합니다.

역할 예시:

- 매크로
- 기업/산업
- 포트폴리오 매니저
- 주문 실행 담당
- 퀀트
- 리스크 매니저
- 컴플라이언스

### 4.8 `orders`

위원회 판단을 실제 주문 후보로 바꿉니다.

현재 원칙:

- 매수는 지정가 중심
- 매도도 지정가 중심
- 현금 범위 안에서만 주문
- 미수/신용 사용 플래그는 항상 꺼짐

### 4.9 `risk`

주문 전 최종 차단기입니다. Atlas Investment에서 가장 중요한 모듈입니다.

반드시 지키는 정책:

- 미수 절대 금지
- 신용 절대 금지
- 킬스위치가 켜지면 모든 주문 금지
- LIVE_AUTO는 별도 정책 허용 전까지 금지
- 단일 종목 비중 제한
- 레버리지/인버스 별도 비중 제한
- 최소 현금 비중 유지
- 하루 주문 금액 제한

### 4.10 `brokers`

브로커 연결 영역입니다.

현재 구현:

- `MockBroker`: 테스트용 가짜 브로커
- `PaperBroker`: 가상 체결용 브로커
- `TossLiveBroker`: 공식 토스증권 API 공개 후 구현할 자리

### 4.11 `journal`

모든 실행 결과를 JSONL 형식으로 기록합니다. 나중에 왜 매수했는지, 왜 차단됐는지, 어떤 주문 후보가 있었는지 추적할 수 있습니다.

## 5. 실행 모드

| 모드 | 의미 |
|---|---|
| `off` | 아무 거래 판단도 실행하지 않음 |
| `dry_run` | 주문 후보와 리스크 판단만 기록 |
| `paper` | 가상 체결까지 수행 |
| `live_auto` | 실거래 자동 주문. 현재는 정책상 비활성 |

## 6. 백테스트 모드

백테스트는 실거래 전에 전략이 과거 데이터에서 어떤 성과를 냈는지 확인하는 기능입니다.

현재 명령 예시:

```bash
PYTHONPATH=src python3 -m atlas_investment.cli backtest --symbol 005930 --strategy moving_average_cross
PYTHONPATH=src python3 -m atlas_investment.cli backtest --symbol AAPL --strategy breakout_momentum
```

결과는 아래 폴더에 JSON으로 저장됩니다.

```text
data/backtests/
```

## 7. 토스증권 API 연결 계획

토스증권 API가 공개되면 다음 순서로 연결합니다.

1. REST 인증 방식 확인
2. 계좌/현금/보유 종목 조회 구현
3. 시세 조회 구현
4. WebSocket 실시간 시세 연결
5. 주문 상태 WebSocket 연결
6. 주문 제출/취소/정정 구현
7. 소액 테스트
8. 제한적 자동매매
9. 완전 자동매매

## 8. 보안과 안전 원칙

- API 키는 코드에 저장하지 않습니다.
- API 키는 `.env` 또는 OS 보안 저장소에 둡니다.
- 실주문 기능은 별도 플래그 없이는 켜지지 않게 합니다.
- 장애 발생 시 신규 주문을 중단합니다.
- WebSocket 연결이 끊기면 신규 주문을 중단합니다.
- REST 응답과 내부 상태가 어긋나면 신규 주문을 중단합니다.
