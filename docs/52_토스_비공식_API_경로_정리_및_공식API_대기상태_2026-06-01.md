# 토스 비공식 API 경로 정리 및 공식 API 대기 상태

작성 시각: 2026-06-01 01:16 KST

## 결론

Atlas Investment에서 토스증권 공식 API가 아닌 실행 경로를 제거했다.

2026-06-12 현재 공식 문서 기준으로 토스증권 Open API는 REST only다. WebSocket URL은 구동 필수값이 아니며, 공식 OpenAPI JSON source of truth는 `https://openapi.tossinvest.com/openapi-docs/latest/openapi.json`이다.

현재 남겨둔 토스 관련 경로는 다음 두 가지뿐이다.

- `TossApiReadiness`: 공식 문서 URL, 공식 OpenAPI JSON URL, REST base URL, OAuth2 client_id/client_secret, accountSeq가 모두 준비됐는지 확인하는 게이트
- `TossLiveBroker`: 공식 API가 공개된 뒤 실제 주문 adapter를 붙일 자리. 공식 문서 검증 전에는 실주문을 차단한다.

## 유지한 공식 API 대기 환경변수

공식 API가 공개되면 아래 값만 연결한다.

```text
TOSS_API_DOCS_URL
TOSS_API_OPENAPI_SPEC_URL
TOSS_API_REST_BASE_URL
TOSS_CLIENT_ID
TOSS_CLIENT_SECRET
TOSS_ACCOUNT_SEQ
```

`TOSS_API_DOCS_URL` 및 `TOSS_API_OPENAPI_SPEC_URL`은 `https://*.tossinvest.com` 또는 `https://*.toss.im` 도메인만 공식 문서 후보로 인정한다.

## Reconciliation 변경

기존 비공식 조회 산출물 경로는 제거했다.

```text
data/toss_readonly/
```

앞으로 공식 API adapter가 생성해야 하는 스냅샷 경로는 다음과 같다.

```text
data/official_broker_snapshots/toss/account.json
data/official_broker_snapshots/toss/account_summary.json
data/official_broker_snapshots/toss/positions.json
data/official_broker_snapshots/toss/open_orders.json
data/official_broker_snapshots/toss/fills.json
```

`reconciliation-check`는 위 공식 스냅샷과 내부 주문 상태를 비교한다. 스냅샷이 없으면 blocked가 정상이다.

## 공식 API 공개 후 연결 순서

1. 공식 문서 URL을 `TOSS_API_DOCS_URL`에 설정한다.
2. 공식 REST base URL과 OAuth2 client credential, accountSeq를 환경변수에 설정한다.
3. `TossLiveBroker`에 공식 인증, 주문, 취소, 정정, 주문상태, 체결 조회 adapter를 구현한다.
4. 공식 계좌/포지션/주문/체결 조회 adapter가 `data/official_broker_snapshots/toss/`에 스냅샷을 쓰게 한다.
5. `reconciliation-check`를 최소 10거래일 무차이로 통과시킨다.
6. DRY_RUN, PAPER, 소액 수동 승인 증거를 남긴 뒤에만 LIVE_AUTO 승격을 검토한다.
