# 전체 진행상황 종합 문서화

> 최신 기준(2026-05-31): Atlas Investment은 토스증권 공식 API 출시 전 안전한 PAPER/DRY_RUN 운용 OS입니다. 완성된 글로벌 헤지펀드 또는 실거래 봇으로 판정하지 않습니다. 토스 플랫폼 범위는 KR/US 주식·ETF·채권·미국주식 옵션 중심이며, 직접 선물·현물 FX·직접 원자재 거래는 공식 지원 전까지 제외합니다. 실거래는 공식 API adapter 구현, read-only reconciliation, 30일 heartbeat, promotion evidence 통과 후에만 검토합니다.

## 문서 목적

이 문서는 2026-05-30부터 2026-05-31까지 Atlas Investment에 실제로 구현·검증·문서화된 전체 내용을 한 곳에 모은 종합 기록이다.

개별 문서 `docs/01`부터 `docs/38`까지가 각 단계의 상세 기록이라면, 이 문서는 운영자가 빠르게 현재 상태와 남은 조건을 판단하기 위한 최상위 요약이다.

## 현재 결론

Atlas Investment은 현재 다음 상태다.

```text
PAPER/DRY_RUN 운용 OS: 작동 및 강화됨
백테스트/전략 연구 플랫폼: 작동
DART 공시 이벤트 신호: API_K_DART 설정 후 작동 확인
로컬 systemd daemon: active
운영 heartbeat: blocked/degraded 상태를 정확히 반영하도록 보강됨
실계좌 자동매매: blocked
글로벌 무인 헤지펀드: blocked
```

`blocked`는 실패가 아니다. 공식 API, 실제 계좌 스냅샷, 라이선스 데이터, 30일 운용 증빙이 없을 때 실거래 승격을 막는 안전장치다.
